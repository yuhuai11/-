# G7严格二分类模型卡

## 模型用途

输入声学录音，输出无人机存在概率。类别定义：

- `label=1`：无人机声音；
- `label=0`：非无人机背景。

模型不输出具体型号。

## 模型结构

```text
16 kHz波形
 → 512点STFT，160点帧移
 → 64维Log-Mel，50～8000 Hz
 → PANNs Cnn14六个卷积块
 → 时间最大池化＋平均池化
 → 2048维Embedding
 → 单输出二分类头
 → Sigmoid概率
```

训练使用AudioSet预训练、背景混合、结构化麦克风频响模拟和频率遮挡。声谱前端和`bn0`在AMP下强制使用float32以降低溢出风险。

## 决策策略

默认模型输入为互不重叠的0.5秒片段。当前证据最好的后处理是：

\[
p_{1s}=\frac{p_{0.5s,t}+p_{0.5s,t+1}}{2}
\]

使用固定阈值0.5进行判断。单个0.5秒概率仍应保留，用于低延迟诊断和与历史结果比较。

## 已知限制

- DADS内部高分不能代表跨设备、跨地点泛化；
- IDMT交通背景误报仍偏高；
- TAU校准的1% FPR阈值迁移到IDMT后约为23.03%；
- 当前外部集合已经消费；
- DADS缺少权威会话、设备、地点和机型元数据；
- 尚未系统报告事件Recall、每小时误报和真实流式延迟；
- 对非WAV格式、极短音频和多通道特殊编码没有完整部署验证。

## 不适用场景

- 不能把概率解释成无人机型号；
- 不能保证任何新城市都保持1% FPR；
- 不应单独依据DADS 99%以上内部Accuracy宣称通用泛化；
- 未经过目标设备校验时，不应直接用于安全关键自动处置。
