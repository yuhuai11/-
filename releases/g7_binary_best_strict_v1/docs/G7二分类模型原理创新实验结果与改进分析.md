# G7二分类模型：原理、工程实现、实验结果与改进方向

更新日期：2026-09-08

## 1. 文档范围与一句话结论

本文只分析工程中的**声学无人机二分类检测模型G7**。它回答的问题是：

> 给定一段声音，判断其中是“无人机声音”还是“非无人机背景声音”。

本文不讨论无人机具体型号分类，也不讨论“已知型号/未知型号”的开放集拒识。因此，当本文提到“未见无人机”或“外部无人机”时，含义是：这些无人机录音没有参与当前G7训练，但G7仍只需要判断它是不是无人机，不需要说出具体型号。

当前最可靠的结论是：

1. G7以AudioSet预训练PANNs `Cnn14_16k`为骨干，在DADS严格内部测试上已经接近饱和；
2. 真正尚未解决的问题不是内部Accuracy，而是跨数据集无人机召回、复杂背景误报和低FPR阈值迁移；
3. 保留0.5秒原生输入、对连续两个预测概率做非重叠1秒均值，是当前证据最稳定的改进；
4. Frequency MixStyle提高了外部无人机召回，但增加了交通背景误报；直接加入大量城市负样本又压低了外部无人机召回；
5. 当前系统有明确的工程与实验设计贡献，但尚不能声称发明了全新的神经网络骨干，也不能把已反复使用的外部集合称为全新独立测试。

## 2. 初学者先理解：二分类检测到底在做什么

一条音频进入系统后，模型输出一个实数logit，再通过Sigmoid变成`0～1`之间的无人机概率：

\[
p(\mathrm{drone}\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}
\]

其中：

- `x`是输入音频；
- `z`是网络输出的logit；
- `p`越接近1，模型越认为存在无人机；
- `p`越接近0，模型越认为是背景；
- 使用固定阈值0.5时，`p≥0.5`判为无人机，否则判为背景。

这个任务看似简单，但部署时存在两个相互制约的目标：

- **召回率要高**：真的有无人机时尽量不要漏检；
- **误报率要低**：车辆、机器、昆虫、风噪等背景不能频繁被误判为无人机。

只看Accuracy很容易掩盖问题。例如背景样本很多时，模型把大多数声音都判成背景，也可能得到较高Accuracy。因此本工程同时观察Recall、FPR、ROC-AUC、PR-AUC和低FPR区域pAUC。

## 3. G7从输入到输出的完整流程

### 3.1 总体框架

```text
原始WAV录音
    │
    ├─ 重采样到16 kHz、单声道、幅值处理
    │
    ├─ 切成原生0.5秒片段
    │
    ├─ STFT时频变换
    │
    ├─ 64维Log-Mel频谱
    │       ├─ 训练期：频率遮挡
    │       └─ 候选实验：Frequency MixStyle
    │
    ├─ AudioSet预训练PANNs Cnn14_16k
    │       ├─ 6个卷积块提取声学特征
    │       ├─ 时间最大池化 + 时间平均池化
    │       └─ 2048维Embedding
    │
    ├─ 二分类线性头
    │
    ├─ Sigmoid无人机概率
    │
    └─ 决策方式
            ├─ 原生0.5秒：单片段直接判定
            └─ 1秒聚合：连续两个0.5秒概率取均值后判定
```

### 3.2 为什么先把声音变成Log-Mel频谱

无人机旋翼和电机通常会形成基频、谐波以及随转速变化的时频结构。直接处理原始波形并非不可能，但Log-Mel频谱具有三个实用优势：

1. 把声音的时间变化和频率组成同时展开，便于二维卷积提取局部纹理；
2. Mel尺度更接近人耳对频率的非线性感知，也能压缩高频表示；
3. 与PANNs的AudioSet预训练前端保持一致，能够有效继承预训练知识。

当前实现参数位于`src/dads_crnn/panns.py`：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| 采样率 | 16,000 Hz | 每秒16,000个采样点 |
| STFT窗长 | 512点 | 约32 ms |
| Hop | 160点 | 相邻帧相隔约10 ms |
| Mel频带数 | 64 | 每一帧压缩成64个频率通道 |
| 最低频率 | 50 Hz | 过滤极低频成分 |
| 最高频率 | 8,000 Hz | 16 kHz采样率下的奈奎斯特上限 |

### 3.3 PANNs骨干网络做了什么

G7正式二分类网络类为`PannsCnn14Binary`。它使用PANNs中的`Cnn14_16k`，先加载在AudioSet大规模声音事件数据上训练的权重，再把原来的527类声音事件输出层替换成一个二分类输出头。

其核心计算可概括为：

\[
\text{Log-Mel}\rightarrow \text{6个卷积块}\rightarrow
\text{时间池化}\rightarrow \mathbf{e}\in\mathbb{R}^{2048}
\rightarrow z\in\mathbb{R}
\]

这里的`2048维Embedding`是模型对输入音频形成的高层声学特征表示。它不是无人机型号，也不是概率，而是一组可供分类头使用的特征数值。二分类头学习如何在这个特征空间里划分“无人机”和“背景”。

### 3.4 为什么采用AudioSet预训练

如果只从无人机数据随机初始化整个深度网络，模型容易记住训练数据中的设备、地点和背景，而没有学到通用声学结构。AudioSet预训练使骨干已经接触过大量真实声音事件，提供更稳定的频谱边缘、谐波、瞬态和环境声表征。

Reuter等人的2026年研究也表明，大规模声音事件预训练是跨域声学无人机检测中最重要的增益来源之一。这个思想与本工程一致，但本工程采用的是PANNs Cnn14，而不是该论文的18层SE-ResNet。

### 3.5 为什么保留0.5秒原生输入

DADS中的大量样本天然只有约0.5秒。保留原生片段有以下原因：

- 不需要把短音频循环填充成1秒，避免重复波形形成容易被模型利用的人造模式；
- 推理延迟低，适合快速检测；
- 能最大限度保持现有预处理和训练资产一致；
- 可以在推理端再进行时间聚合，而不用重新训练骨干。

0.5秒的代价是单片段可能只包含弱旋翼声、瞬时噪声或不完整周期结构，因此单片段决策更容易波动。

### 3.6 1秒概率聚合为什么有效

当前聚合不把两个波形重新拼接送入网络，而是分别计算两个连续0.5秒片段的无人机概率，再求均值：

\[
p_{1s}=\frac{p_{t}+p_{t+1}}{2}
\]

这会削弱偶发噪声造成的单次高分，同时保留连续存在的无人机信号。它不改变模型权重，不增加训练成本，只会把决策延迟由约0.5秒增加到约1秒。

需要特别注意：只有属于**同一连续录音**的相邻片段才能聚合。不同录音、不同设备或不同地点的数据不能为了凑够时长而拼接。

## 4. 训练方法

### 4.1 严格基线配置

当前最适合科研报告的G7基线是`g7_strict_retrain_v1`，主要设置为：

| 项目 | 设置 |
|---|---|
| 训练数据 | 严格修正后的DADS二分类数据 |
| 输入 | 原生、互不重叠的0.5秒片段 |
| 划分 | 内容组件隔离的70%训练、15%验证、15%内部测试 |
| 随机种子 | 42、43、44 |
| Batch size | 128 |
| 最大Epoch | 15 |
| 初始学习率 | `1e-4` |
| 学习率衰减 | 0.75 |
| 早停耐心值 | 4个epoch |
| 优化目标 | 带自动`pos_weight`的二元交叉熵 |
| 混合精度 | 启用AMP |
| 最佳模型选择 | 验证集固定阈值0.5的F1 |

二元交叉熵的基本形式为：

\[
\mathcal{L}_{BCE}=-w_+y\log p-(1-y)\log(1-p)
\]

其中`w+`用于调整正负样本不均衡对梯度的影响。

### 4.2 训练期增强

严格基线采用与物理声学变化相关的增强：

1. **背景混合**：以0.33概率把正类无人机与背景混合，信噪比为10～20 dB；
2. **麦克风频响模拟**：以0.33概率模拟高通、低通和若干峰值均衡器，近似不同录音设备；
3. **频率遮挡**：以0.5概率遮住部分Mel频带，防止模型依赖单一窄频带；
4. **AudioSet预训练初始化**：不是增强，但构成最重要的泛化基础。

这些方法的目的不是随意扰乱音频，而是让训练样本覆盖更合理的SNR、设备频响和频带缺失情况。

### 4.3 工程稳定性保护

模型实现还包含几个容易被忽视但很重要的保护：

- 校验官方预训练权重SHA，防止加载错误文件；
- 在AMP训练中强制声谱前端和`bn0`使用float32，降低数值溢出风险；
- 保存配置和检查点身份，支持复现实验；
- 数据划分前进行多种内容哈希和近重复审计。

这些不是新的分类算法，但对科研可复现性和结果可信度非常重要。

## 5. 数据集在二分类实验中的角色

### 5.1 DADS：训练、验证和严格内部测试

修正后的DADS共有417,221个互异的0.5秒窗口：

| 划分 | 窗口数 | 占比 | 用途 |
|---|---:|---:|---|
| Train | 292,053 | 70% | 更新模型参数 |
| Validation | 62,584 | 15% | 早停和检查点选择 |
| Internal Test | 62,584 | 15% | 训练完成后的内部回归测试 |

全体标签约为222,415个背景窗口和194,806个无人机窗口。

划分不是简单随机按切片拆分，而是先将精确相同或内容关联的记录组成不可拆分组件，再按组件划分。Train/Test之间的原始WAV、float32模型输入、PCM16等价输入和内容组件精确交集均为0。

但是DADS缺少权威的长录音、飞行事件、地点、日期、设备和采集会话元数据。因此仍不能完全排除同一采集会话被预切成多个文件后分散到不同集合。DADS内部测试应称为“同数据源、已消费的严格内部回归测试”，不能冒充独立跨域泛化结果。

### 5.2 外部数据：跨域开发压力测试

| 数据集 | 当前角色 | 主要用途 | 限制 |
|---|---|---|---|
| TAU Prague | 校准背景 | 估计1%和5% FPR阈值 | 单一城市阈值不能代表所有背景域 |
| Kielce/TAU | 开发Benchmark | 外部无人机召回和背景误报 | 无人机/背景与语料来源高度混杂 |
| G13 DDL+AeroSonic | 开发Benchmark | 未见无人机召回、ROC/PR/pAUC | 来源组存在标签纯组问题 |
| IDMT Traffic | 负类压力集 | 交通背景FPR | 只有负类，不能计算无人机Recall |
| ESC-50 guard | 负类保护集 | 非交通环境声音FPR | 规模较小且只有负类 |

外部集合均已在历史实验中被多次查看，因此目前是**可重复开发Benchmark**，不是一次性、未见过的最终测试集。

另外，Kielce全部为正类而配套TAU全部为负类，数据来源本身就能预测标签。这意味着模型可能部分利用录音设备或语料特征，而不是只利用无人机声。Kielce/TAU结果必须与G13、IDMT和ESC-50一起解释，不能单独作为泛化结论。

## 6. 指标如何理解

设TP为正确检出的无人机，FN为漏检无人机，FP为被误判成无人机的背景，TN为正确识别的背景。

| 指标 | 公式/含义 | 本项目中的作用 |
|---|---|---|
| Accuracy | `(TP+TN)/(TP+TN+FP+FN)` | 总体正确率，类别不均衡时不能单独使用 |
| Precision | `TP/(TP+FP)` | 报警中有多少是真的无人机 |
| Recall/TPR | `TP/(TP+FN)` | 真无人机被检出的比例 |
| F1 | Precision与Recall的调和平均 | 平衡漏检和误报，但不直接限定低FPR |
| FPR | `FP/(FP+TN)` | 背景被误报为无人机的比例，越低越好 |
| ROC-AUC | 各阈值下TPR与FPR曲线面积 | 衡量总体排序能力 |
| PR-AUC | 各阈值下Precision-Recall曲线面积 | 正类稀少时更有解释力 |
| 标准化pAUC | 只计算`FPR≤0.05`区域的ROC面积 | 关注低误报部署区间 |
| TPR@1% FPR | 把阈值调到约1% FPR时的召回 | 直接描述低误报工作点 |

部署时还应增加事件级Recall、每小时误报警次数和检测延迟。片段FPR并不等于真实系统每小时会报警多少次。

## 7. 当前严格基线的实验结果

### 7.1 DADS内部测试：三随机种子

固定阈值0.5，结果为均值±样本标准差：

| 评价单位 | Accuracy | F1 | Recall | FPR |
|---|---:|---:|---:|---:|
| 原生0.5秒片段 | 0.994700 ± 0.000245 | 0.994346 ± 0.000259 | 0.998083 ± 0.000181 | 0.008262 ± 0.000555 |
| 原始文件均值聚合 | 0.998611 ± 0.000057 | 0.999239 ± 0.000031 | 0.999171 ± 0.000103 | 0.007296 ± 0.001547 |

这说明模型在DADS同源数据上的二分类能力很强，而且三个随机种子较稳定。但它不能证明模型面对新设备、新地点、新噪声时也具有同样性能。

近重复审计发现Train/Test精确交集为0；进一步排除33个波形余弦相似度不低于0.99的Test源文件后，指标没有下降，因此已发现的高相似候选不能解释当前高分。剩余风险主要来自缺失会话级元数据，而不是已经确认的精确重复泄漏。

### 7.2 外部数据：原生0.5秒、固定阈值0.5

| 数据集 | Recall | FPR | ROC-AUC | PR-AUC | pAUC，FPR≤0.05 |
|---|---:|---:|---:|---:|---:|
| Kielce/TAU | 0.920897 ± 0.015027 | 0.011193 ± 0.000779 | 0.990593 ± 0.002196 | — | — |
| G13 | 0.750804 ± 0.012129 | 0.093610 ± 0.001926 | 0.921953 ± 0.003453 | 0.657687 ± 0.019936 | 0.726201 ± 0.014215 |
| IDMT Traffic | — | 0.213482 ± 0.033123 | — | — | — |
| ESC-50 | — | 0.031250 ± 0.002083 | — | — | — |

最重要的现象是：内部Recall约99.8%，到了G13只有约75.1%；内部FPR约0.83%，到了IDMT交通背景达到约21.35%。这就是明显的跨域差距。

### 7.3 TAU低FPR阈值为什么没有成功迁移

在TAU Prague背景上把阈值校准到1% FPR后，迁移到其他数据集得到：

| 数据集 | Recall | 实际FPR |
|---|---:|---:|
| Kielce/TAU | 0.924322 ± 0.019654 | 0.013126 ± 0.001874 |
| G13 | 0.763703 ± 0.030028 | 0.101185 ± 0.010276 |
| IDMT Traffic | — | 0.230321 ± 0.055244 |
| ESC-50 | — | 0.034722 ± 0.007887 |

校准阈值均值约为0.454，但在IDMT上的实际FPR达到23.03%。这说明“在一个背景域上是1% FPR的阈值”，换到另一个背景域后不一定还是1%。阈值迁移是当前最明确的部署风险之一。

### 7.4 1秒非重叠概率均值：当前最稳定的改进

固定阈值0.5时，将连续两个0.5秒概率取均值：

| 数据集/指标 | 0.5秒 | 1秒 | 变化 |
|---|---:|---:|---:|
| Kielce/TAU Recall | 0.920897 | 0.951454 | +0.030557 |
| Kielce/TAU FPR | 0.011193 | 0.006373 | -0.004820 |
| G13 Recall | 0.750804 | 0.783964 | +0.033160 |
| G13 FPR | 0.093610 | 0.083998 | -0.009611 |
| G13 ROC-AUC | 0.921953 | 0.936829 | +0.014876 |
| G13 PR-AUC | 0.657687 | 0.695486 | +0.037800 |
| G13 pAUC | 0.726201 | 0.742118 | +0.015917 |
| IDMT FPR | 0.213482 | 0.196120 | -0.017362 |
| ESC-50 FPR | 0.031250 | 0.026389 | -0.004861 |

所有主要方向同时改善。因此“原生0.5秒模型＋非重叠1秒概率均值＋固定0.5阈值”是当前证据最充分的部署候选。

但是，如果在1秒单位上重新用TAU校准1% FPR阈值，G13、IDMT和ESC-50的实际FPR反而增加。这再次说明：**时间聚合有效，不等于跨域阈值问题已经解决。**

## 8. G7各阶段究竟改进了什么

### 8.1 严格G7基线

严格版本的主要价值是修正实验协议，而不是声称创造了新网络：

- 使用内容组件隔离的Train/Validation/Test；
- 去除旧流程中与标签强相关的1秒循环填充捷径；
- 完成精确哈希与近重复审计；
- 使用三个随机种子报告均值和标准差；
- 冻结外部数据角色，区分内部回归和跨域压力测试。

严格seed42与早期G7-R2 seed42的参数逐张量完全相同。因此严格版本的新增价值是**协议可信度和稳定性证据**，不能把它描述成seed42算法性能提升。

### 8.2 G7-R6：加入DroneNoise数据

R6检验“增加无人机数据是否自然提升泛化”。结果是Kielce/TAU明显改善，但G13和IDMT退化。以seed42的0.5秒固定阈值结果为例：

- Kielce/TAU Recall约从0.9102提高到0.9873，FPR约从0.0108降到0.0011；
- G13 Accuracy约从0.8921降到0.8674，F1约从0.5770降到0.5066；
- IDMT FPR约从0.1799升到0.2028。

结论是：数据类型更多不一定自动更好。若新数据的设备、背景或类别比例偏向某个域，模型可能更擅长该域，却损害其他域。

### 8.3 G7-R7：Frequency MixStyle

R7只加入一个无参数的频率统计混合模块。它在训练期随机混合样本间的频率统计，希望减少模型对录音设备和频响的依赖。

seed42的一秒/录音级结果：

| 指标 | 严格基线 | R7 | 变化 |
|---|---:|---:|---:|
| G13 ROC-AUC | 0.937001 | 0.951441 | +0.014440 |
| G13 PR-AUC | 0.688070 | 0.763102 | +0.075031 |
| G13 pAUC | 0.738079 | 0.789265 | +0.051186 |
| G13 Recall | 0.783408 | 0.811618 | +0.028211 |
| IDMT FPR | 0.156682 | 0.177707 | +0.021025，退化 |
| ESC-50 FPR | 0.025000 | 0.016667 | -0.008333 |

R7说明频率统计扰动确实能改善未见无人机的可分性，但它同时扩大了部分背景被判成无人机的区域。尤其IDMT的`background_only` FPR从0.075416升到0.113594。由于没有同时通过预先设定的门槛，R7没有晋级，也没有继续训练seed43/44。

当前实现会在整个batch内随机配对，可能发生正类与负类频率统计互混。这是IDMT误报增加的合理怀疑，但尚未被对照实验严格证实。

### 8.4 G7-R8：加入城市负样本

R8在R7基础上加入43,320个TAU训练域城市负样本，希望压低交通背景误报。结果：

| 指标 | R7 | R8 | 变化 |
|---|---:|---:|---:|
| IDMT FPR | 0.177707 | 0.098889 | -0.078818，改善 |
| G13 ROC-AUC | 0.951441 | 0.927236 | -0.024205 |
| G13 PR-AUC | 0.763102 | 0.676363 | -0.086738 |
| G13 pAUC | 0.789265 | 0.733357 | -0.055908 |
| G13 Recall | 0.811618 | 0.739421 | -0.072197 |

城市负样本确实把IDMT误报压了下来，但分类边界向负类方向收缩过强，使外部无人机漏检增加。R8未晋级，也没有继续训练seed43/44。

这个结果提示下一步不能再简单堆叠更多负样本，而要控制不同来源和类别在每个batch中的暴露比例、训练更新次数和损失贡献。

## 9. 与公开论文方法的关系

### 9.1 Reuter等，2026

论文《Improving acoustic drone detection generalization through pretraining and data augmentation》研究跨数据集声学无人机二分类检测。其关键方法包括：

- 大规模音频事件预训练；
- 麦克风频响模拟；
- 无人机与背景按10～20 dB SNR混合；
- 频率遮挡；
- 1秒和2秒输入比较；
- 在目标FPR为1%或5%的工作点报告TPR；
- 使用多随机种子和会话隔离划分。

该论文中预训练带来的提升最明显。例如其IDMT-Test AUC由无预训练的约0.972升至约0.983，TPR@1% FPR由约0.860升至约0.920；完整增强组合并非每项都在所有外部域上持续增加。

本工程已经采用预训练、麦克风响应增强、背景混合和频率遮挡，说明当前瓶颈不是“还缺这一套基础增强”，而更可能是训练域多样性、来源平衡、会话隔离和阈值迁移。

论文链接：[arXiv:2605.31329](https://arxiv.org/abs/2605.31329)

### 9.2 Vilhurin等，2026

论文《Acoustic UAV Detection in Battlefield Scenarios: Handling Noise, Domain Shift, and Weak Labels》关注强噪声、域偏移和弱标签条件下的二分类检测，采用：

- PCEN时频前端；
- ImageNet预训练ConvNeXt-Tiny；
- 可学习频率投影；
- 弱标签注意力聚合；
- 噪声注入Mixup、域感知训练、SWA和课程式遮挡；
- 连续时间流隔离，避免相邻片段跨集合。

该工作证明域偏移处理和噪声注入可以显著提升困难场景性能。但不能把其全部增益归因于某一个模块，因为骨干、输入时长、前端、训练数据和评估协议同时不同。

PCEN值得做独立实验，但不能直接替换G7前端后宣称公平提升：PANNs预训练权重是基于原有Log-Mel分布学习的，贸然改为PCEN可能破坏预训练特征匹配。

论文链接：[arXiv:2608.14287](https://arxiv.org/abs/2608.14287)

### 9.3 哪些不是本工程原创

下列方法都有公开研究基础，不应写成项目原创算法：

- PANNs、Cnn14和AudioSet预训练；
- STFT、Log-Mel、BCE和Adam类优化；
- 频率遮挡、背景混合和麦克风频响增强；
- MixStyle/Frequency MixStyle思想；
- 多片段概率均值；
- ROC-AUC、PR-AUC、pAUC和低FPR阈值评估。

公开方法可以合法用于科研并发表论文，但论文必须正确引用来源，说明自己的实现和新增贡献，不能把已有模块包装成原创。

## 10. 当前可以主张的创新与贡献

当前贡献更适合定义为**面向真实跨域部署的系统方法与实验协议创新**，而不是全新骨干网络。

### 10.1 泄漏感知的数据划分与证据链

工程不仅按文件名划分，还构建内容组件，检查原始WAV、PCM16等价内容、float32模型输入和跨集合近重复，并明确区分“精确重复已排除”与“缺少会话元数据仍无法排除”的边界。

### 10.2 原生0.5秒输入与1秒决策聚合

该设计兼顾0.5秒快速响应和1秒稳定决策，在不重训模型的情况下，对多个外部数据集同时实现召回提高与FPR降低。概率均值本身并非新算法，但它与DADS原生短样本、禁止循环填充及跨域低误报评估形成了项目特定的完整方案。

### 10.3 多域、低FPR、来源级的统一评估框架

工程不再只报告内部Accuracy，而是同时观察外部无人机召回、交通背景FPR、环境声音FPR、pAUC和阈值迁移，并用预先设定的多指标门槛阻止“一个域提升就宣布成功”。

### 10.4 对失败实验进行可解释的边界分析

R7和R8形成一组有研究价值的负结果：

- 扩大频率统计覆盖可以提高外部无人机召回，但可能扩大背景误报；
- 强化城市负样本可以压低交通误报，但可能收缩正类边界并损害未见无人机召回。

这种跨域权衡及来源子组分析，比只展示最好Accuracy更接近可发表的真实研究问题。

### 10.5 工程可复现性

预训练权重校验、前端FP32保护、严格检查点身份、数据生命周期标记以及机器可读指标，使实验更容易复验。这属于有价值的工程贡献，但应与算法创新分开表述。

一个较准确的论文方向可以表述为：

> 面向跨域低误报声学无人机检测的泄漏感知预训练与多时间尺度聚合方法。

在获得新的独立测试集和完成关键消融之前，不建议声称“提出了全新网络”或“达到通用无人机检测”。

## 11. 当前工程仍存在的问题

### 11.1 科研问题

1. **跨域误报仍高**：严格基线在IDMT的0.5秒FPR约21.35%，1秒聚合后仍约19.61%；
2. **阈值不能稳定迁移**：TAU上的1% FPR工作点迁移到IDMT后约为23.03%；
3. **正负域存在对抗性权衡**：R7改善G13却恶化IDMT，R8改善IDMT却恶化G13；
4. **缺少未消费最终Holdout**：当前外部数据已被反复查看；
5. **缺少权威会话元数据**：DADS内部高分仍不能完全排除同采集会话相关性；
6. **缺少连续流指标**：尚未系统报告每小时误报、事件Recall和检测延迟。

### 11.2 训练与评估实现问题

1. 当前训练按验证集`F1@0.5`选择最佳检查点，与低FPR部署目标不完全一致；
2. 外部预测缓存主要检查形状和有限值，尚应绑定检查点SHA、数据清单哈希、预处理配置和代码版本，避免误读旧缓存；
3. 数据防火墙在注册信息缺失时应严格失败关闭，不能静默继续；
4. R8虽然固定了`pos_weight`，但新增大量负样本仍改变了每个epoch的自然曝光和梯度构成；
5. R7的整批随机MixStyle可能跨正负类混合统计，需要类别条件对照；
6. 仓库中历史正式G7曾使用1秒设置，而严格/R7/R8使用0.5秒，需要统一模型注册表，避免部署时选错模型；
7. 当前没有完整的连续音频流推理和报警去抖服务。

### 11.3 结果表述问题

以下表述应避免：

- “DADS Accuracy 99%以上，所以模型具备强外部泛化能力”；
- “TAU校准到1% FPR，所以部署到任何场景都是1%误报”；
- “Kielce/TAU结果高，所以模型完全识别未知无人机”；
- “增加了公开数据，所以一定提升泛化”；
- “使用了论文模块，所以该模块就是本工程原创”。

## 12. 下一步建议：只围绕二分类检测

### P0：先完善实验可信度，不需要GPU

1. 建立唯一的G7模型注册表，记录检查点SHA、输入时长、预处理、训练清单、代码提交和结果文件；
2. 给预测缓存加入检查点、数据清单、预处理和代码哈希；
3. 数据防火墙改为fail-closed：角色或注册信息缺失就停止；
4. 冻结现有外部集为开发Benchmark，后续不再把它们称为新测试；
5. 明确当前默认候选为“严格三seed G7＋0.5秒输入＋1秒非重叠均值”。

### P1：G7-R9来源/类别均衡训练

R9优先解决R8的“负样本剂量过大”问题，不立即换骨干、不叠加多个新模块：

1. 每个batch分别控制无人机与背景数量，例如128样本中约60正类、68负类；
2. 背景内部再按DADS和TAU来源采样，使TAU城市负样本只占背景的0%、5%、10%形成剂量消融；
3. 固定每轮更新次数，避免数据增多自动改变优化步数；
4. 固定类别先验或重新推导`pos_weight`，明确区分采样分布与目标部署先验；
5. seed42只做预注册筛选；全部门槛通过后再训练42、43、44三个种子。

核心目标不是只压低IDMT FPR，而是在保留G13 Recall/pAUC的同时降低IDMT误报。

### P2：让模型选择指标与部署目标一致

将“验证F1@0.5”与低误报目标分开比较，增加以下候选选择准则：

- 验证集标准化pAUC，`FPR≤0.05`；
- TPR@1% FPR或TPR@5% FPR；
- 多来源最坏组Recall/FPR；
- 受约束目标：在FPR不超过上限时最大化Recall。

为了公平，必须用相同训练结果对比不同选择准则，不能在外部Benchmark上选择epoch。

### P3：类别条件Frequency MixStyle或RFN单变量实验

R7的主要怀疑是跨类别混合频率统计。可只改变一个变量：

- 同一类别内部进行MixStyle；或
- 只在背景内部进行来源间混合；或
- 使用频率归一化/扰动方法，但不与其他模块同时加入。

必须保留R7作为原始对照，先做seed42；只有G13与IDMT门槛同时通过才进行三seed复验。

### P4：连续流和多时间尺度评估

在同一原始录音确有连续片段时比较：

- 0.5秒即时决策；
- 1秒非重叠均值；
- 1秒滑动均值；
- 2秒聚合。

报告事件Recall、每小时误报次数、平均检测延迟和最坏场景表现。当前数据中某些录音组只有两个0.5秒视图，不能跨录音拼接出虚假的2秒样本。

### P5：PCEN或弱标签注意力作为后续独立分支

参考Vilhurin等人的方向，可以测试低SNR更稳健的PCEN和弱标签时间注意力，但应遵守：

1. 一次只改变一个主要变量；
2. PCEN与Log-Mel使用相同数据、划分和随机种子；
3. 明确PCEN可能与PANNs预训练输入分布不匹配；
4. 不通过内部安全门和外部开发门就停止，不继续盲目叠加。

### P6：建设真正独立的最终评估集

最有价值的新数据不是简单再下载一个“全是无人机”的语料，而是成对采集：

- 同一地点、同一设备、同一时段附近的无人机存在/不存在录音；
- 包含不同距离、姿态、机型、SNR、风速和交通强度；
- 按采集会话、地点和设备整体隔离；
- 在模型和阈值冻结后才评估。

这样才能削弱“数据来源等于标签”的混杂，并对跨域泛化作出可信结论。

## 13. 建议的晋级规则

任何新候选模型至少同时满足：

1. DADS内部F1和Recall不超过预先规定的容忍下降；
2. G13的ROC-AUC、PR-AUC、pAUC和Recall至少保持或改善；
3. IDMT和ESC-50 FPR不恶化；
4. Kielce/TAU不出现明显Recall损失；
5. 低FPR阈值迁移误差不恶化；
6. seed42通过后，三个种子的均值、标准差和置信区间仍支持结论；
7. 未使用测试标签做样本选择、早停、阈值调节或超参数搜索。

不能用某一项大幅提升抵消另一项关键失败。例如R8的IDMT FPR虽然明显降低，但G13 Recall和pAUC明显下降，因此不能晋级。

## 14. 最终判断

G7已经不是一个简单的“把音频送入CNN”的原型，而是由预训练声学骨干、物理相关增强、泄漏感知划分、多域低FPR评估和时间聚合组成的完整二分类研究框架。

它当前最强的地方是：DADS内部性能高、三seed稳定、数据泄漏审计较完整，且1秒概率聚合在多个外部方向上得到一致改善。

它当前最弱的地方是：复杂交通背景误报仍高，单域阈值不能迁移，外部数据已经被消费，并且R7/R8揭示出正类跨域召回与背景误报之间的明显冲突。

因此下一阶段不应继续追求内部Accuracy的小数点提升，也不应盲目增加数据或堆叠模块。最合理的主线是：

> 来源/类别均衡训练 → 低FPR目标一致的模型选择 → 类别条件频率泛化 → 连续流事件评估 → 新会话级独立Holdout。
