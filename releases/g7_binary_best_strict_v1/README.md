# G7二分类最佳严格版本发布包

发布包日期：2026-09-09

## 1. 版本身份

本目录整理的是当前工程中**已经完成三随机种子训练、内部测试、外部测试并正式保留的最佳二分类基线**：

> AudioSet预训练PANNs Cnn14＋物理相关增强＋严格DADS内容隔离＋原生0.5秒输入＋非重叠1秒概率均值。

本版本只判断“无人机/非无人机背景”，不识别具体无人机型号，也不进行未知型号拒识。

没有选择R7、R8或R9作为发布模型，原因是：

- R7提高G13指标，但增加IDMT交通背景误报，没有通过全部晋级门；
- R8降低IDMT误报，但明显损失G13外部无人机Recall，没有晋级；
- R9只有实验代码和协议，尚未完成GPU训练，没有新模型结果。

## 2. 推荐使用方式

- **单模型部署首选：seed42。** 三个严格seed中，它在IDMT交通背景上的FPR最低，适合作为更保守的当前部署起点；
- **科研报告：seed42、43、44全部保留。** 使用三seed均值和标准差，不选择性只报告最好seed；
- **决策方式：原生0.5秒模型输入，连续两个概率做非重叠1秒均值，固定阈值0.5。**

seed44的G13/Kielce Recall更高，但IDMT FPR也明显更高，因此不存在所有数据集上都占优的单一seed。“seed42部署首选”是基于误报风险的工程选择，不代表它在每个外部指标上都是最高值。

## 5. 大文件保存方式

本目录逻辑大小约52GB。为避免重复复制，模型、大型NumPy缓存和音频文件使用同文件系统硬链接整理：

- 发布目录与原目录是两个目录项；
- 删除原目录不会删除发布目录中的内容；
- 修改文件内容会影响所有硬链接，因此发布资产应视为只读；
- 将本目录复制到其他磁盘或打包时，会实际写出约52GB数据。

源码、配置、说明文档和需要重写相对路径的清单使用独立副本。

发布包内的`.gitignore`会阻止`artifacts/`和`data/`被误加入源码仓库；它不会删除本地文件。
