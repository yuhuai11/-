# G7第二阶段：IDMT跨域背景R0基线

## 1. 本阶段做了什么

本阶段没有训练新模型，也没有调整G7参数。使用冻结的G7 seed 42对IDMT-TRAFFIC
Development Test进行纯负类跨域测试。

数据防火墙状态：

```text
IDMT Calibration音频读取：否
IDMT Development Test音频读取：是
Hohenwarte Final Holdout音频读取：否
训练启动：否
```

Development Test包含：

| 单位 | 数量 |
|---|---:|
| 2秒录音 | 14,673 |
| 非重叠1秒窗口 | 29,346 |
| 同步交通事件 | 7,341 |
| 录音会话 | 13 |
| 独立地点 | 2 |

所有样本对无人机检测任务都是负类。因此本阶段不能计算TPR、ROC-AUC、PR-AUC、pAUC、
Precision和F1，主要评价FP、FPR和Specificity。

## 2. 数据兼容和排重

IDMT使用48 kHz双声道IEEE Float WAV，原工程只支持整数PCM。本阶段扩展了解码器，并
通过Float32双声道、24位PCM和音频身份单元测试。

IDMT活动数据与DADS 180,305条唯一来源进行了三层确定性比较：

```text
原始WAV字节SHA256
统一16 kHz规范PCM SHA256
增益归一规范PCM SHA256
```

三层精确重合均为0，标签冲突为0，因此没有删除IDMT样本。频谱近邻只作为人工复核
候选，不使用未经校准的相似度阈值自动删除数据。

## 4. 正式GPU结果

### 4.1 窗口级结果

| 工作点 | FP | 实际FPR | Specificity |
|---|---:|---:|---:|
| 冻结目标FPR 1% | 1,960 | 0.066789 | 0.933211 |
| 冻结目标FPR 5% | 5,126 | 0.174675 | 0.825325 |
| 历史概率阈值0.5 | 5,323 | 0.181388 | 0.818612 |

主工作点FPR的Clopper-Pearson 95%区间为：

```text
[0.063959, 0.069706]
```

按录音会话聚类Bootstrap得到：

```text
[0.057213, 0.076669]
```

这说明历史1%工作点迁移到IDMT交通域后，实际窗口FPR约为6.68%，明显高于原目标。

### 4.2 录音与事件聚合

主工作点下：

| 聚合方法 | FP单位 | FPR |
|---|---:|---:|
| 单个1秒窗口 | 1,960 / 29,346 | 0.066789 |
| 2秒录音任一窗口阳性 | 1,702 / 14,673 | 0.115995 |
| 2秒录音平均概率阳性 | 518 / 14,673 | 0.035303 |
| 2秒录音两个窗口均阳性 | 258 / 14,673 | 0.017583 |
| 同步事件任一设备、任一窗口阳性 | 1,544 / 7,341 | 0.210326 |

“任一窗口阳性”会放大误报；简单平均可以降低误报，但它仍不是已经训练和验证的学习型
聚合器，不能直接作为新正式策略。

### 4.3 主要分组

| 分组 | FPR |
|---|---:|
| 高质量sE8麦克风（SE） | 0.019359 |
| MEMS麦克风（ME） | 0.114200 |
| 纯背景 | 0.006869 |
| 车辆经过 | 0.120199 |
| Langewiesener-Strasse | 0.065063 |
| Schleusinger-Allee | 0.069645 |

更细的交叉结果：

| 麦克风 | 内容 | FPR |
|---|---|---:|
| SE | 纯背景 | 0.004774 |
| ME | 纯背景 | 0.008962 |
| SE | 车辆经过 | 0.032354 |

当前最主要的问题不是普通静态背景，而是低成本MEMS设备记录的车辆经过声。该组合FPR
达到20.80%，应成为G7-R1麦克风频响模拟和困难交通负类训练的主要目标。

## 7. 后续执行结果

下一阶段G7-R1已经完成。R1保持G7-R0数据清单和评价协议不变，只将原G7的通用平滑
频响增强替换为结构化麦克风频响模拟。候选模型使用与基线相同的`val_ood_tune`
校准规则独立拟合温度和阈值，IDMT Development Test不参与训练或校准。

R1通过了历史DADS同数据源已消费内部回归、`val_ood_holdout`和G9机械声门禁，但IDMT严格FPR从
`0.066789`上升到`0.179854`，6项IDMT晋级门禁全部失败，因此已否决，不进入
seed 43/44，也未读取Hohenwarte Final Holdout。

只读复核还发现原平滑频响与R1结构化频响共用增强随机数流，两个算子消耗随机数的
数量不同，连带改变了后续混响、噪声和时移轨迹。该问题不影响“当前R1候选应否决”，
但限制了对IIR算子本身的严格因果归因。下一步先做独立随机流的同期双臂配对消融。
