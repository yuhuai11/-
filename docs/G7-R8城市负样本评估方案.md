# G7-R8 城市负样本评估方案

## 1. 要回答的问题

G7-R7 的 Frequency MixStyle 提高了 G13 未见无人机检测，但使 IDMT 交通背景 FPR 上升。R8 只回答一个问题：**加入来源隔离的城市环境训练负样本，能否恢复交通背景误报，同时保留 R7 的跨域无人机增益？**

IDMT 已是反复使用的外部 Benchmark，不允许从中选择误报片段、训练、校准阈值或早停。R8 使用 TAU 中预先划为 `train` 的 Barcelona、London、Paris 等城市负样本；Prague 仍只校准阈值，外部 Holdout 保持评估角色。

## 2. 实验变量与控制项

- 基线：G7-R7 Frequency MixStyle seed42。
- 候选：G7-R8 Frequency MixStyle + TAU-train 城市负样本直接重放。
- 新增训练数据：43,320 个 0.5 秒视图，21,660 条录音，39 个来源组，全部 `label=0`。
- TAU 负样本不进入正样本背景混合器，避免同时改变波形增强机制。
- 使用自然随机打乱、不放回，不使用 hard mining，也不根据 IDMT 分数挑选样本。
- 模型、AudioSet 初始化、MixStyle、频率掩蔽、优化器、学习率、epoch、早停和随机种子与 R7 相同。
- 固定 `pos_weight=1.1416534670890532`，即 R7 的实际 DADS 类别权重，避免新增负样本隐式改变损失权重。
- DADS validation/test 的样本及顺序与 R7 完全相同。

因此，本轮可解释为一个数据层单变量：加入合法训练域的城市负样本直接重放。

## 3. 分阶段执行

### P0：数据与代码预检

必须全部通过：

1. TAU replay 仅来自 `split=train`，不存在 calibration、holdout、IDMT、G13 或 ESC-50 行。
2. 绑定既有模型输入精确哈希审计：development 与 calibration/Kielce/G13/IDMT/ESC-50 重合均为 0。
3. TAU 全部为负类且 `background_mix_eligible=false`。
4. DADS validation/test 身份保持不变。
5. CPU 真实加载与 GPU 单步前向、反向、优化器预检均为有限值。

P0 失败则不得训练。

### P1：seed42 内部筛选

只训练 seed42。内部 DADS 测试以固定阈值 0.5 报告片段级和录音级 Accuracy、F1、Recall、FPR、ROC-AUC、PR-AUC。安全门槛：

- 录音级 F1 相对 R7 下降不超过 0.003；
- 录音级 Recall 相对 R7 下降不超过 0.005；
- 片段级 F1 相对 R7 下降不超过 0.003。

任一失败则停止，不消费外部 Benchmark。

### P2：冻结外部配对评估

冻结 seed42 最佳权重后，使用与 R7 相同的原生 0.5 秒和非重叠 1 秒均值方案。主要评价单位为 1 秒/录音级；固定阈值 0.5 为晋级依据，TAU-Prague 的 1%/5% FPR 校准阈值只作阈值迁移诊断。

必须同时满足：

1. IDMT FPR ≤ 0.156682（恢复至严格基线水平）；
2. G13 标准化 pAUC ≥ 0.779265（允许相对 R7 最多下降 0.010）；
3. G13 Recall ≥ 0.801618（允许相对 R7 最多下降 0.010）；
4. G13 ROC-AUC ≥ 0.946441（允许相对 R7 最多下降 0.005）；
5. ESC-50 FPR ≤ 0.021667（允许相对 R7 最多增加 0.005）；
6. Kielce/TAU 1 秒 Recall 相对 R7 下降不超过 0.010，FPR 不高于严格基线 0.006536。

同时报告 IDMT `background_only` 与 `vehicle_passing` 子类 FPR、G13 PR-AUC、校准阈值迁移和来源组指标。不能用某一项大幅提升抵消另一项失败。

### P3：三随机种子复验

只有 P1、P2 全通过才训练 seed43/44。最终报告 seed42/43/44 均值与样本标准差，并进行录音/来源组配对 bootstrap 95% CI。当前外部集合已被多次使用，所以即使通过，也只能称为“可重复开发 Benchmark 晋级”，不能宣称全新独立外部泛化结论。

## 4. 停止条件

- 数据防火墙或精确身份审计失败；
- 内部安全门槛失败；
- IDMT FPR 未恢复；
- 为压低 IDMT 而明显损失 G13 未见无人机指标；
- 需要根据 IDMT 样本或标签继续挑选训练数据。

发生上述任一情况即封存 R8，不继续盲目堆叠损失函数、采样器或额外增强模块。

## 5. seed42 实际结果

训练在 epoch 11 正常早停，最佳 checkpoint 来自 epoch 7，验证 F1 为
0.994226。P1 内部安全门槛全部通过：片段 F1 相对 R7 只下降 0.000712，
录音级 F1 基本不变，录音级 Recall 提高 0.000245。

P2 冻结外部配对评估未通过：

| 1 秒录音级指标 | G7-R7 | G7-R8 | R8-R7 |
|---|---:|---:|---:|
| IDMT FPR | 0.177707 | 0.098889 | -0.078818 |
| G13 ROC-AUC | 0.951441 | 0.927236 | -0.024205 |
| G13 PR-AUC | 0.763102 | 0.676363 | -0.086738 |
| G13 pAUC（FPR≤0.05） | 0.789265 | 0.733357 | -0.055908 |
| G13 Recall | 0.811618 | 0.739421 | -0.072197 |
| ESC-50 FPR | 0.016667 | 0.020833 | +0.004167 |
| Kielce/TAU Recall | 0.934018 | 0.939040 | +0.005022 |
| Kielce/TAU FPR | 0.004412 | 0.000490 | -0.003922 |

IDMT 的 `background_only` FPR 从 0.113594 降至 0.035286，
`vehicle_passing` 从 0.234854 降至 0.155581，说明城市负样本确实解决了目标误报。
但是 G13 mini Recall 从 0.767733 降至 0.675025，pro4 从 0.868053 降至
0.822232。候选模型的负类边界收缩过强，牺牲了未见无人机召回。

最终判定：IDMT、ESC-50、Kielce 三类门槛通过；G13 ROC-AUC、pAUC、Recall
三类门槛失败。R8 不晋级、不训练 seed43/44，保留为“城市负样本剂量过大”的
消融证据。机器可读结果位于
`artifacts/g7_r8_urban_negatives/external_evaluation/metrics.json`。
