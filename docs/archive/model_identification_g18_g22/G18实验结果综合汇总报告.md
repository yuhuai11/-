## 1. 执行摘要

当前工程已经形成一条完整的分层声学识别链路：

```text
前端声学信号
→ G7：无人机/背景检测
→ G18：已知无人机型号分类
→ 线性Outlier Exposure：Known/Unknown判断
```

主要结论必须拆成三部分理解。

### 1.1 G7无人机检测

G7在历史 DADS 同数据源已消费内部回归集上的无人机/背景二分类指标很高：

| 指标 | 历史DADS已消费内部回归集 |
|---|---:|
| Accuracy | 0.996426 |
| Balanced Accuracy | 0.995936 |
| Precision | 0.995422 |
| Recall | 0.998567 |
| Specificity | 0.993305 |
| F1 | 0.996992 |
| ROC-AUC | 0.999854 |
| PR-AUC | 0.999913 |

这里的历史DADS清单是在每个标签内随机把Parquet行（`AudioRef`）分配到Train、
Validation和Test，再把每行展开成1秒片段；同一行的片段不跨split，但
`source_path`不是实际分组键，其零交集只是事后身份审计结果。后验原始WAV字节级
SHA256审计发现15个重复哈希组，共涉及30条Parquet记录；每组保留1条并移除15条，

多轮候选回归门禁使用，只能称为历史DADS同数据源已消费内部回归集。

旧`dads_dedup_v2`仅去除原始WAV字节级精确重复，仍复用历史1秒
`loop/tail_loop`预处理和缓存，未消除标签相关的时长/重复捷径。新的G7主复现应采用
`dads_native_half_second_content_component_v2`原生0.5秒内容组件隔离协议。因此
上述历史结果不代表跨会话、跨设备、跨场景或跨型号的独立泛化。

G7在G18最终180条无人机录音上的严格模式和平衡模式检测Recall均为`1.000000`。
因此G18最终实验的主要失败不在“是否检测到无人机”，而在“是否能把新型号拒识为
Unknown”。

## 2. 任务与指标口径

### 2.1 G7任务

G7执行二分类：

```text
0 = 背景/非无人机
1 = 无人机
```

主要指标：

- Recall/TPR：真实无人机被检出的比例；
- Specificity：真实背景被正确排除的比例；
- FPR：背景被误报为无人机的比例，等于`1-Specificity`；
- F1：Precision与Recall的调和平均；
- ROC-AUC：不依赖单一阈值的排序能力；
- PR-AUC：类别不平衡时的Precision-Recall综合能力；
- 低FPR partial AUC：只关注低误报工作区。

### 2.2 G18已知型号任务

已知型号共九类：

1. MAVIC2PRO
2. MAVIC2ZOOM
3. MAVIC3
4. MAVICAIR2
5. MAVICAIR2S
6. MAVICMINI2
7. PHANTOM4
8. YUNEECH520
9. YUNEECH520ERTK

主要指标：

- 闭集Accuracy：假设输入一定属于九个已知型号，只检查型号是否正确；
- Macro-F1：每个型号F1等权平均，避免样本较多型号支配结果；
- 最低类别Recall：九类型号中表现最差的一类；
- Known接纳率：已知型号没有被错误拒识为Unknown的比例；
- 型号端到端Accuracy：同时满足“被接纳为Known”和“型号预测正确”。

### 2.3 G18开放集任务

开放集任务需要区分：

```text
Known UAV   = 属于九个训练过的型号
Unknown UAV = 无人机，但型号不属于九个已知类别
```

主要指标：

- Unknown Recall：Unknown被正确拒识的比例；
- Unknown误接纳率：Unknown被错误当成某个已知型号的比例；
- 开放集平衡准确率：
  `(Known接纳率 + Unknown Recall) / 2`；
- Known/Unknown AUROC：Known分数对两类样本的整体排序能力。

注意：`passed: true`在JSON报告中表示代码、哈希和协议完整执行，不代表所有性能指标
达到应用要求。P6虽然`passed: true`，但Unknown泛化结论是失败。

## 8. Unknown候选方法比较

所有方法使用相同Known Tune和Unknown Tune评价口径。

| 方法 | Known接纳率 | Unknown Recall | Bal.Acc | AUROC | Known闭集Acc | Known端到端Acc | 结论 |
|---|---:|---:|---:|---:|---:|---:|---|
| MSP | 0.901099 | 0.177778 | 0.539438 | 0.627717 | 0.978022 | 0.901099 | 停止 |
| PCA余弦原型 | 0.901099 | 0.388889 | 0.644994 | 0.677778 | 0.472527 | 0.450549 | 停止 |
| PCA类条件kNN-5 | 0.923077 | 0.400000 | 0.661538 | 0.739683 | 0.978022 | 0.901099 | 停止 |
| PCA+线性OE | 0.989011 | 0.944444 | 0.966728 | 0.991453 | 0.978022 | 0.967033 | 开发集通过 |

### 8.1 MSP失败

MSP阈值为`0.392841`。Known与Unknown最大Softmax置信度高度重叠：

- Known置信度中位数：0.557375；
- Unknown置信度中位数：0.525408；
- 90条Unknown中74条被误接纳。

交叉熵分类器会把未知输入高置信度映射到最相似的已知类，最大Softmax概率本身不具备
稳定的开放集距离含义。

### 8.2 原型方案失败

余弦原型将Unknown Recall提高到`0.388889`，但闭集Accuracy降至`0.472527`。该方案
破坏了原有分类能力，不满足工程目标。

### 8.3 kNN方案失败

kNN保留闭集Accuracy `0.978022`，AUROC提高到`0.739683`，但Unknown Recall只有
`0.400000`，未达到预设0.50门槛。

### 8.4 线性OE开发集成功

线性OE使用MATRICE300/S900显式学习Known/Unknown边界。它是首个同时保留闭集分类并
通过开发门槛的方案，但其成功依赖两个已见Unknown型号，不能自动推广到其他新型号。

- 在历史DADS同数据源已消费内部回归集上获得较高的无人机/背景二分类指标；
- 对当前九个已知型号进行较好的录音级分类；
- 在相同设备和相近采集域下，Known Holdout闭集Accuracy约91.2%；
- 对连续多片段录音比对单个1秒片段更可靠；
- 提供可审计的模型、配置、数据清单和结果哈希。

### 11.2 尚不具备的能力

- 不能可靠拒识任意未见无人机型号；
- 不能证明跨录音设备、跨城市、跨环境和跨季节稳定；
- 不能根据一次前端录音无条件给出可信型号；
- 不能把高Known概率直接解释为“型号确定”；
- 不能把P5开发集94.44%的Unknown Recall作为真实新型号性能。

### 11.3 合理的当前输出策略

若用于实验性演示，应明确输出：

```text
Background
Known型号候选 + 置信度
Unknown/需人工复核
```

同时应声明当前Unknown标志不可靠，尤其是与PHANTOM4声学特征相似的新型号。

## 12. 为什么开发集高而最终Unknown低

主要原因不是代码随机波动，而是开放集数据覆盖不足。

1. OE只见过MATRICE300和S900；
2. 线性分类器学到的是“Known与这两个Unknown”的分界；
3. X6D/Y6在embedding空间中落入PHANTOM4区域；
4. 三个随机种子给出相同Unknown Recall，排除了偶然seed解释；
5. 全局线性边界无法表达“靠近某个已知类但仍属于新型号”的复杂类别条件结构；
6. 单设备、有限采集环境可能使模型学习设备、旋翼布局或采集会话相关线索。

这说明Outlier Exposure的Unknown型号多样性与隔离方式，比继续微调同一阈值更重要。

## 13. 后续实验建议

### 13.1 数据协议

P6已经消费，X6D/Y6不能再次作为无偏最终测试。下一代实验应：

1. 把X6D/Y6明确登记为已消费开发数据；
2. 将其用于PHANTOM4相似Unknown的错误分析或OE训练；
3. 获取至少两个从未参与开发的新无人机型号；
4. 新增跨设备、跨地点、跨距离和跨噪声条件；
5. 在训练开始前按型号冻结新的Unknown Holdout；
6. 新Holdout只运行一次。

### 13.2 算法方向

建议建立G19，而不是继续修改P6：

- 类别条件Mahalanobis距离；
- 监督对比学习或Triplet/Proxy度量学习；
- ArcFace/CosFace等角度间隔分类；
- Energy-based Open-Set分数；
- OpenMax或EVT尾部分布建模；
- 包含PHANTOM4相似Unknown的Outlier Exposure；
- 多层embedding或多特征后期融合；
- 单独进行录音级开放集训练，而不仅在片段embedding后拟合线性头。

所有候选只能在新的开发分区比较，不能在P6上择优。

### 13.3 建议的晋级门

下一代正式测试前建议至少满足：

```text
多种子Known闭集Macro-F1稳定
多Unknown型号Tune Recall达到预设门槛
最差Unknown型号Recall达到门槛
Known接纳率不低于预设保护线
类别条件错误不集中坍缩到单一已知型号
跨设备或跨会话开发验证通过
```

Unknown总体Recall不能掩盖某个型号Recall为0的情况，应把最差Unknown型号Recall列为
强制门槛。

## 15. 最终结论

当前声学无人机检测与开放集型号识别工程已经完成了从二分类无人机检测到开放集型号识别的完整、可复现、
带数据防火墙的实验流程。

可以成立的结论：

1. G7在内部无人机检测任务上性能很高；
2. 冻结G7 embedding包含明显的无人机型号信息；
3. 九个已知型号在最终同域Holdout上的录音级闭集Accuracy约91.2%；
4. 多片段录音聚合显著优于单个1秒片段；
5. 现有线性OE在MATRICE300/S900开发集上有效。

不能成立的结论：

1. 现有Unknown拒识能泛化到任意新型号；
2. 当前系统已经实现可靠开放集型号识别；
3. 开发集94.44%的Unknown Recall代表真实未见型号性能；
4. 只选择seed 42即可解决最终泛化问题；
5. 调整P6阈值后可以重新宣称最终结果改善。

最准确的工程判断是：

> 当前模型已经具备较好的“无人机检测 + 九个已知型号分类”能力，但Unknown新型号拒识
> 仍是核心瓶颈。下一阶段应以新数据协议和类别条件开放集学习为主，而不是继续优化已
> 消费Holdout上的阈值。
