# G18基于G7的分层开放集无人机型号识别方案

详细方法、公式和流程图见：
[G18方法原理与完整流程说明](G18方法原理与完整流程说明.md)。

## 1. 目标

在不破坏正式G7二分类检测器的前提下，将工程扩展为：

```text
前端声学信号
  ↓
信号质量与有效性检测
  ↓
G7：无人机/非无人机检测
  ↓ 仅当检测为无人机
G18：型号识别
  ↓
具体型号 / Unknown UAV
```

G18是开发候选，不自动替代G7。G7继续负责低误报的无人机存在检测；G18只处理
G7判定为无人机的片段。

## 2. 当前能力边界

G7训练标签只有`0=背景、1=无人机`，不能直接输出具体型号。G18复用G7二分类头前的
2048维embedding，并增加独立机型分类头：

```text
G7 PANNs Cnn14_16k
  ├─ 原二分类头：保持冻结
  └─ 2048维embedding → LayerNorm → 9类Linear Head
```

初始阶段只训练约1.8万参数的机型头，G7约7996万参数全部冻结。这样可以：

- 保持正式G7检测能力不变；
- 降低小数据训练造成的灾难性遗忘；
- 快速判断G7 embedding是否包含型号信息；
- 为后续G17高频embedding融合保留接口。

## 4. 数据隔离

原G14划分面向二分类，并不适合型号识别。多数型号只对应一个采集来源组，直接沿用会
导致某些型号只出现在训练集或只出现在留出集。

G18-P0采用独立的原始录音级划分：

```text
split_unit = raw_audio_sha256
```

同一原始录音的全部一秒片段只能属于一个分区。每条原始录音最多保留20个均匀位置
片段，防止长录音支配训练。

P0实际生成：

| 分区 | 片段 | 原始录音 | 用途 |
|---|---:|---:|---|
| known_train | 8,080 | 404 | 训练分类头 |
| known_tune | 1,820 | 91 | 早停和已知类校准 |
| known_holdout | 1,820 | 91 | 已知型号开发留出 |
| unknown_tune | 1,800 | 90 | Unknown阈值选择 |
| unknown_holdout | 1,780 | 89 | Unknown开发留出 |

五个分区的原始音频SHA256交集全部为0，已消费G13哈希重叠为0，封存测试集读取为空。

## 5. 分层推理规则

对于每个时间窗：

```text
if G7无人机概率 < detection_threshold:
    输出 Background
else:
    计算9类型号概率
    if 最大型号置信度 < known_confidence_threshold:
        输出 Unknown UAV
    else:
        输出具体型号
```

`known_confidence_threshold`不能主观指定，必须使用`known_tune + unknown_tune`选择，
随后冻结并仅在`known_holdout + unknown_holdout`评估一次。

正式前端使用时应聚合连续3～10秒，而不是依赖单个一秒片段：

```text
逐窗口G7门控
→ 有效无人机窗口embedding
→ 原始录音级平均logit或多数投票
→ Unknown门控
→ 型号与置信度
```

## 8. 当前局限

Kielce型号录音全部来自`OLYMPUS_LS11`，且多数型号只有单一采集会话。因此当前结果
可能学习：

- 采集日期和环境；
- 型号对应的固定距离组合；
- 同一架无人机的个体声纹；
- 单一麦克风频响；
- 数据制作流程。

原始录音级隔离能防止相邻片段泄漏，但不等于跨设备、跨地点、跨无人机个体泛化。
要满足真实前端部署目标，后续仍需采集：

- 每型号至少多个物理个体；
- 多种麦克风；
- 多地点和多背景；
- 多距离、高度和姿态；
- 未参与训练的新型号；
- 与实际前端完全一致的采样率、增益和编码链路。

P3采用固定、单一的开放集评分，避免在同一个Unknown开发集上比较大量拒识算法后择优：

```text
每段9类logits
  → 同一原始录音内平均logits
  → softmax
  → 最大类别概率MSP
  → 低于冻结阈值时输出Unknown UAV
```

约束的候选阈值中最大化Known接纳率与Unknown拒识率的平均值。并列时依次优先Unknown
召回、Known接纳率和更保守的低阈值。P3不绑定、不读取`known_holdout`或
`unknown_holdout`。

## 15. G18-P3b PCA余弦类别原型探针

P3b只检验一个机制明确的候选，不在同一Tune上枚举多种开放集分数：

```text
P2训练后的2048维LayerNorm embedding
  → 每条原始录音平均
  → 仅用known_train录音拟合32维PCA
  → L2归一化
  → 每个已知型号计算一个known_train类别原型
  → 与所有原型计算余弦相似度
  → 最大相似度线性映射到[0, 1]
  → Tune上按与P3相同规则冻结Unknown阈值
```

PCA和类别原型完全不读取Unknown；`unknown_tune`只参与最终阈值选择和Tune晋级判定。
P3b不训练网络、不更新G7或P2机型头。它继续使用P3冻结的四项门槛，并继续禁止读取
`known_holdout`、`unknown_holdout`和所有历史最终测试集。

### 23.3 P6结论与后续数据边界

当前系统可以较好识别九个已知型号，但不能可靠地把从未见过的无人机型号输出为
`Unknown`。因此不能把当前方案描述为已经实现可靠的开放集无人机型号识别。

P6 Holdout已经永久关闭。后续允许：

1. 将X6D/Y6结果仅用于错误分析和下一代算法设计；
2. 将当前P6数据明确降级为“已消费开发数据”，用于下一代训练或Outlier Exposure；
3. 引入更多结构差异明显的Unknown型号、跨录音设备、跨环境和跨距离数据；
4. 研究类别条件距离、度量学习、监督对比学习、能量分数或开放集专用损失；
5. 在任何新方案训练前，先建立型号级隔离的全新未见Unknown Holdout。

后续不允许：

1. 在X6D/Y6上搜索阈值后重新把同一结果称为最终测试；
2. 根据P6选择seed 42并只报告其结果；
3. 删除本次失败结果或重新运行P6；
4. 在没有新未触碰Holdout的情况下宣称Unknown泛化已经改善。
