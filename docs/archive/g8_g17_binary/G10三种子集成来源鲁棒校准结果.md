# G10三种子集成来源鲁棒校准结果

## 结论

G10最终判定为`do_not_promote`，不得整体替代G7。其严格1%工作点通过全部冻结门禁，但5%工作点的holdout TPR和UAV来源宏平均TPR略低于G7，违反预先规定的零退化条件。门槛不根据本次holdout结果修改。

## 排序指标

G10的holdout ROC-AUC为0.824689、PR-AUC为0.821353、标准化低FPR部分AUC为0.618365，均高于G7。这进一步表明主要限制位于工作点校准，而不是模型排序能力。
