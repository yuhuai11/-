# G11最终双工作模式评估协议

## 候选系统

候选系统固定为G9 seed 42、43、44的raw-logit算术平均，使用G10在val_ood tune上拟合的温度。禁止选择单个最佳种子。

## 工作模式

- 严格模式：采用G10已冻结的1%来源鲁棒阈值。
- 均衡模式：采用G10三种子集成在val_ood tune负类上产生的5% pooled阈值。
- G7对照分别采用其已冻结的1%和5% pooled阈值及温度。

上述选择发生在最终测试解锁之前。Unseen和Real-world不参与模式、温度、阈值或模型选择。

## 最终数据

最终评估固定为Unseen和Real-world。首次打开前必须生成冻结协议，并提供显式解锁口令。解锁后创建协议绑定标记；技术中断只能在相同协议和缓存身份下恢复，禁止修改规则后重新评估。

## 晋级门槛

对每个最终数据集和每个工作模式，候选系统相对G7必须同时满足FPR不升、TPR不降、F1不降。候选ROC-AUC、PR-AUC和标准化低FPR部分AUC也必须在每个数据集上不低于G7。任一门槛失败则整体`do_not_promote`。

## 重复样本与统计

主指标按冻结清单的样本分布计算。置信区间按SHA256聚类自助法计算，避免Unseen增强样本的重复哈希被当作完全独立证据。另报告去重SHA256指标，不用于事后改变晋级规则。

## 审计约束

最终结果记录协议、实现、配置、检查点、校准文件、清单和预测缓存SHA256。最终数据读取记录必须明确列为`unseen`和`real_world`，不得再声称最终测试未读取。
