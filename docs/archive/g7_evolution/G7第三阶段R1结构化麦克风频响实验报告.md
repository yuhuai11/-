# G7第三阶段：R1结构化麦克风频响实验报告

## 1. 结论

G7-R1仅把原G7的平滑随机频响增强替换为结构化麦克风频响模拟，seed 42已经完成
训练、内部回归、外部开发门禁和IDMT-TRAFFIC开发集评估。

最终决策为：

```text
reject_r1_seed42_after_idmt_development
```

R1在历史DADS同数据源已消费内部回归集、`val_ood`和G9机械声保护集上通过门禁，但在IDMT-TRAFFIC
交通背景上明显增加误报，6项IDMT晋级条件全部失败。因此：

1. 不运行seed 43和44；
2. 不把R1并入正式G7；
3. 不读取Hohenwarte Final Holdout；
4. 后续实验从原G7/R0重新分支，不在R1上继续叠加新模块。

这是一个有效的候选否决实验，而不是无效实验。它证明“当前代码和随机轨迹下实际训练
得到的R1 seed 42候选”不能改善当前工程的跨域误报。由于后文说明的共享随机数流
混杂，尚不能把全部退化严格因果归于结构化IIR算子本身。

---

## 2. 实验问题

本实验只回答一个问题：

> 将G7已有的通用平滑随机频响，替换为更接近真实设备响应的高通、低通和峰值均衡
> 组合，能否在保持历史DADS同源内部回归性能的同时，降低跨设备、机械声和交通背景误报？

除频响子模块和输出目录外，训练数据、模型、AudioSet初始化、随机种子、优化器、
训练轮数、其他增强概率和评价协议保持不变。因此它是“配置字段层面的单变量消融”。
但现有增强器的多个操作共享同一个随机数生成器，不同频响实现会改变后续增强抽样轨迹，
所以还不是严格的逐样本配对单变量实验。

---

## 3. 参考方法与工程实现

参考方法来自Paul M. Reuter等人的论文：

> *Improving acoustic drone detection generalization through pretraining and data augmentation*，
> arXiv:2605.31329，Quiet Drones 2026。

论文使用声音事件预训练与在线增强，并将麦克风传递函数模拟作为完整增强链的一部分。
本工程只抽取其中的结构化频响思想进行独立消融，不能把本实验等同于复现论文的完整
数据、模型和增强链。

R1的频响结构为：

```text
一阶高通：60～120 Hz
一阶低通：6000～8000 Hz
峰值均衡：随机2～3段
单段增益：-4～+4 dB
中心频率：120～6000 Hz，对数均匀采样
Q值：0.5～2.0
实现：二阶节级联（SOS）
激活概率：0.50
```

高通、低通、峰值均衡数量和增益范围继承参考论文；中心频率分布与Q值是本工程在训练
前固定的工程选择。激活概率保留G7原值`0.50`，用于隔离“频响结构”变化。因为增强
末尾存在峰值归一化，未加入会被归一化抵消的全局增益项。

模型仍为：

```text
PANNs Cnn14_16k
AudioSet预训练初始化
参数量：79,955,457
输入：16 kHz单声道、1秒片段
任务：无人机/非无人机二分类
```

## 7. IDMT-TRAFFIC开发集结果

IDMT-TRAFFIC Development Test包含：

```text
29,346个1秒片段
14,673条双通道录音
7,341个事件
13个录音会话
全部标签为非无人机
```

因为该集合没有正类，不能从它计算TPR、Recall、Precision、F1、ROC-AUC、
PR-AUC或pAUC。这里只能合法报告FPR、Specificity和误报暴露率。

### 7.1 主要结果

| 指标 | G7/R0 | R1 | R1相对R0 |
|---|---:|---:|---:|
| 严格阈值整体FPR | 0.066789 | 0.179854 | +0.113065，约2.69倍 |
| 严格阈值误报片段 | 1,960 | 5,278 | +3,318 |
| 5%灵敏阈值整体FPR | 0.174675 | 0.338683 | +0.164009 |
| ME×车辆声FPR | 0.208043 | 0.486466 | +0.278422 |
| SE麦克风FPR | 0.019359 | 0.081663 | +0.062304 |
| 纯背景FPR | 0.006869 | 0.032393 | +0.025524 |
| 固定沿用G7映射的R1整体FPR | — | 0.135623 | 仍明显劣于R0 |

候选模型在13个会话中的宏平均FPR为0.180107，最差会话FPR为0.227143。

### 7.2 配对会话Bootstrap

以录音会话为重采样单位，固定seed `20260731`执行2,000次Bootstrap：

```text
R1 - R0 FPR差：+0.113065
双侧95%区间：[+0.098546, +0.124641]
单侧95%上界：+0.123004
晋级要求：单侧95%上界严格小于0
```

区间整体大于0，说明退化不是由少数片段偶然造成，而是在会话层面具有一致性。

### 7.3 是否只是阈值问题

不是。

1. 使用R1自己的Tune校准阈值时，整体FPR为0.179854；
2. 固定沿用G7阈值映射时，整体FPR仍为0.135623；
3. R0与R1得分相关系数为0.853，但R1概率中位数由R0的0.291836上移到0.359979；
4. 有3,470个R0严格判阴性的片段被R1判成阳性，反向改善只有152个。

用原始Logit阈值进一步分解：

```text
G7严格Logit阈值：2.173828
R1自身严格Logit阈值：1.442383

R0自身映射FPR：0.066789
R1使用固定G7映射FPR：0.135623
R1使用自身Tune映射FPR：0.179854
```

因此，总计`+0.113065`的FPR退化中，约`+0.068834`来自模型在IDMT上的原始得分
上移，约`+0.044231`来自候选Tune阈值降低后的进一步放大，约为61%和39%。即使完全
不迁移阈值，R1误报也已约为R0的两倍。

这种漂移具有明显域相关性。相对正式G7，R1配对Logit的平均变化为：

```text
val_ood_tune负类：-0.184
val_ood_holdout负类：-0.274
IDMT纯负类：+0.992
```

IDMT中约79.7%的片段R1 Logit高于G7，且13/13个会话的严格FPR都同方向恶化。
这解释了为什么IDMT之前的门禁可以改善，而交通域仍然失败。

事后若把R1阈值抬到约`0.843993`，可在IDMT上匹配R0的整体FPR，但
`val_ood_holdout` TPR会下降到`0.126027`，低于正式G7的`0.236986`。该阈值又是
看过IDMT后得到的，不能用于正式模型选择。

因此，退化来自交通声上的模型分数分布漂移，不能用简单重新校准阈值解决。

## 8. 为什么内部改善而IDMT退化

目前证据支持以下解释，但不能把它写成已经证明的因果结论：

1. 当前增强器用同一个随机数流控制频响、混响、彩色噪声和时移；原`8-anchor`
   平滑频响固定消耗8个正态随机数，结构化IIR则消耗数量可变的高通、低通、段数、
   中心频率、Q值和增益随机数。这会使频响之后的增强门控和参数发生变化，是当前实验
   最重要的控制混杂；
2. `val_ood`和G9覆盖的背景类型，与IDMT连续道路交通、轮胎、发动机和风噪组合不同；
3. 结构化频响增强可能使模型更不依赖设备的细节频谱，同时意外增强了对持续机械谐波
   的不变性，使车辆声更容易被映射为无人机；
4. R1只替换了一个增强子模块，而参考论文的结论来自预训练、更多无人机/背景数据和
   完整增强链，单独模块不保证在所有数据域都产生正收益；
5. ME、SE和纯背景均退化，说明问题不局限于一个麦克风通道。

本实验不能推出“论文方法无效”，只能推出：

> 当前实际训练得到的R1 seed 42候选不适合作为G7升级，也不应进入多随机种子和
> Final Holdout。若要严格判断IIR算子本身，必须先消除共享随机数流混杂。

## 9. 下一步

### 9.1 立即执行

1. 保留R1全部结果作为否决消融；
2. 不继续seed 43/44；
3. 不读取Hohenwarte Final Holdout；
4. 不通过IDMT后调阈值或缩窄频响范围来追逐本次结果；
5. 先修复增强器共享随机数流造成的实验控制混杂；
6. 下一候选必须重新冻结，并继续使用相同的Tune、Holdout、G9和IDMT顺序。

### 9.2 下一项推荐实验：独立随机流的同期双臂配对消融

在继续R2之前，先建立真正的频响单变量对照：

```text
C0：原G7 smooth_fft
C1：structured_microphone_v1
```

实现要求：

1. 为背景混合、频响门控与参数、混响、彩色噪声、时移分别使用由同一seed派生的独立
   随机数流，或为每个样本和epoch生成确定性的增强计划；
2. 两个实验臂的batch顺序、频响激活掩码及所有非频响增强门控和参数逐样本一致；
3. 频响关闭的样本输出必须bit-exact，频响开启时非频响metadata必须完全相同；
4. 训练前保存增强轨迹哈希并写入冻结协议；
5. 两个实验臂都从相同AudioSet权重同期训练，只运行seed 42；
6. 仍按DADS、`val_ood`、G9、IDMT Development顺序评估。

若严格配对后的C1仍在固定G7映射和候选自身校准两种口径下显著退化，才能更有把握地
否定当前结构化频响算子。该实验属于新的预注册实验，不能覆盖本次R1产物。

### 9.3 后续R2：低SNR正类背景混合

完成上述控制实验后，R2仍应从正式G7/R0分支，只改变低SNR正类背景混合：

```text
正式G7/R0
  ├─ 严格配对频响消融
  └─ R2：低SNR正类背景混合
```

R2应在训练前固定SNR档位、采样概率、背景身份去重和同一组保护门槛。IDMT纯负类
不能直接加入训练或用于挑选SNR档位。若需要困难交通负类训练，应另行获取与IDMT身份
隔离的训练数据。

若仍需研究“结构化频响剂量”，可在严格配对实验之后另行预注册一个固定的
`75% smooth_fft + 25% structured IIR`诊断分支；不能在IDMT Development上网格
搜索比例，也不能读取Final Holdout。
