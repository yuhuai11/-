# G3：Full CRNN来源均衡采样方案

## 1. 目的与单变量原则

G2证明训练期声学增强能将val_ood holdout Recall从0.6000提高到0.7178、AUC从0.6754提高到0.7607，但不同录音来源之间仍存在明显差异。G3保持G2的Full CRNN、Log-Mel、增强参数、优化器、训练轮数和验证方式不变，只改变train split的抽样分布。

首轮只训练seed 42。Unseen和Real-world继续保持锁定，不参与筛选。

## 2. 失衡审计

Full train包含212,502个片段，来自126,224条原始录音：

| 类别 | 片段数 | 原始录音数 |
|---|---:|---:|
| Background | 87,974 | 11,710 |
| UAV | 124,528 | 114,514 |

单条UAV长录音最多贡献304个片段。自然shuffle会使长录音在一个epoch内重复影响梯度。

## 3. 三级采样

每次抽样按以下概率执行：

```text
类别等概率(0.5/0.5)
  → 类别内原始录音等概率
    → 该录音的片段等概率
```

实现采用等价的片段权重：

```text
w(segment) = 1 / (类别数 × 该类别录音数 × 该录音片段数)
```

每个epoch仍抽取212,502条，使用有放回抽样。固定seed和`num_workers: 0`保证随机序列可复现。val/test仍顺序、无放回且无训练增强。

原方案通过自然类别比例和`pos_weight=0.7065`实现两类总损失平衡；G3抽样后类别比例为1:1，自动`pos_weight`相应变为1.0，因此两类期望损失贡献仍相等。

## 5. 服务器训练

在工程根目录执行：

```bash
mkdir -p logs
nohup env PYTHONPATH=src CUDA_VISIBLE_DEVICES=0 \
  /usr/local/anaconda3/envs/dads-crnn/bin/python -u -m dads_crnn.train \
  --config configs/crnn_dads_full_augmented_g3_source_balanced.yaml \
  --manifest artifacts_full/manifests/dads_all_seed42.csv \
  --seeds 42 \
  > logs/g3_crnn_full_seed42.log 2>&1 &
echo $!
```

监控：

```bash
tail -f logs/g3_crnn_full_seed42.log
nvidia-smi
```

```text

```

## 6. 训练完成后的val_ood评估

```bash
nohup env PYTHONPATH=src CUDA_VISIBLE_DEVICES=0 \
  /usr/local/anaconda3/envs/dads-crnn/bin/python -u -m dads_crnn.calibrate_ood \
  --checkpoint archive/historical_models/failed_candidates/artifacts_crnn_full_augmented_g3_source_balanced/runs/seed_42/best.pt \
  --tune-manifest artifacts/val_ood/manifests/val_ood_tune_manifest.csv \
  --holdout-manifest artifacts/val_ood/manifests/val_ood_holdout_manifest.csv \
  --output-dir artifacts/val_ood \
  --experiment crnn_full_augmented_g3_source_balanced \
  --batch-size 256 --num-workers 0 --device auto \
  --target-recall 0.80 --target-specificity 0.90 \
  > logs/g3_crnn_full_seed42_val_ood.log 2>&1 &
echo $!
```

通过门槛保持不变：DADS Test F1相对原Full CRNN下降不超过1个百分点，val_ood holdout Recall不低于80%、Specificity不低于90%。未达标时不扩展seed 43/44。

## 7. Seed 42实测结果（2026-07-17）

训练在epoch 36早停，最佳checkpoint为epoch 26，总耗时90.71分钟。

| 模型 | DADS Test F1 | Recall | Specificity | AUC |
|---|---:|---:|---:|---:|
| 原Full CRNN seed 42 | 0.99835 | 0.99824 | 0.99775 | 0.99989 |
| G2 seed 42 | 0.99522 | 0.99467 | 0.99384 | 0.99970 |
| G3 seed 42 | 0.95316 | 0.91205 | 0.99754 | 0.98452 |

G3相对原Full CRNN的F1下降4.52个百分点，超过1个百分点保护门槛，因此实验判定失败，不进入val_ood、不扩展seed 43/44，也不查看最终外部测试集。阈值0.40、0.50、0.65的F1分别为0.95392、0.95316、0.95228，且AUC明显下降，说明问题并非阈值选择。

完全均衡存在过度校正：UAV每个epoch的期望抽样数从124,528降至约106,251，并因有放回抽样只覆盖约69,414/114,514条UAV录音；同时长录音的权重被按片段数完全反比削弱。这降低了正类覆盖和有效多样性。后续若继续采样方向，应使用保留自然类别比例的温和来源权重（例如片段数的负二分之一次方），而不是完全三级均衡。
