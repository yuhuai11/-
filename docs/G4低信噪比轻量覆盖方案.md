# G4：低信噪比轻量覆盖与安全晋级方案

## 1. 结论先行

G4采用“champion–challenger”方式：G2始终作为当前最佳模型保存，G4使用独立目录训练，只有通过全部保护门槛才允许晋级。实验无法在训练前保证新权重一定更优；本方案能严格保证的是，失败的G4不会覆盖或替换G2。

G4唯一训练变量是正类背景混合的SNR概率分布：

```yaml
# G2
mix_snr_db: [-5, 0, 5, 10]
mix_snr_weights: [0.10, 0.25, 0.35, 0.30]

# G4
mix_snr_db: [-10, -5, 0, 5, 10]
mix_snr_weights: [0.05, 0.10, 0.25, 0.35, 0.25]
```

即从`+10 dB`移动5%条件概率到`-10 dB`。不加入`-15 dB`，不使用G3来源均衡，不改变模型、特征、优化器、采样、epoch或其他增强。

## 2. 量化依据

### 2.1 G3失败归因

G3将DADS Test F1从G2的0.99522降至0.95316，且AUC从0.99970降至0.98452。完全来源均衡使每epoch正类抽样数由124,528降至约106,251，有放回抽样只覆盖69,414/114,514个正类来源。G3在长录音`full`片段上的FNR达到87.10%，G2仅4.29%。因此后续不再改变自然shuffle，也不再对来源做替换式均衡。

### 2.2 G2仍然有效

G2相对原Full CRNN在val_ood holdout上的变化：

| 指标 | Full CRNN | G2 | 差值 |
|---|---:|---:|---:|
| F1 | 0.62084 | 0.70955 | +0.08871 |
| Recall | 0.60000 | 0.71781 | +0.11781 |
| Specificity | 0.67295 | 0.69987 | +0.02692 |
| AUC | 0.67536 | 0.76072 | +0.08536 |

G2的整体配对改善显著（McNemar约`p=1.0e-6`）。G2对未训练过的`-10 dB`条件也已将Recall从0.5093提高到0.6296，说明声学增强具有向更低SNR外推的基础。

### 2.3 为什么只加入少量-10 dB

G2 holdout的206个正类漏检中，`-10/-15 dB`合计95个，占46%。但`-15 dB` Recall由原Full的0.5306降到G2的0.4388；极弱无人机信号接近纯背景，过多正标签可能增加假阳性。因此首轮只加入5%的`-10 dB`条件概率。

Full train正类占0.58601，正类背景混合概率为0.70，因此真正改变的全训练样本比例为：

```text
0.58601 × 0.70 × 0.05 = 0.02051（约2.05%）
```

每epoch预计约4,358条`-10 dB`正类混合样本；30%的正类仍完全不做背景混合。

## 3. 冻结项与产物隔离

以下内容与G2完全一致：

- Full DADS manifest和自然shuffle；
- 64-bin Log-Mel和Full CRNN；
- batch size、Adam、学习率、early stopping；
- `pos_weight: auto`和`num_workers: 0`；
- 混响、频响、彩色噪声、时间平移及其概率；
- DADS val checkpoint选择方式；
- seed 42快速筛选。

G4独立输出：

```text
archive/historical_models/failed_candidates/artifacts_crnn_full_augmented_g4_low_snr/runs/
```

训练入口默认拒绝覆盖非空run目录。除非人工明确传入`--allow-overwrite`，现有实验不会被重复运行覆盖。

## 6. 分阶段门控

### 6.1 第一关：DADS内部非劣筛选

训练完成后先复核G2哈希：

```bash
PYTHONPATH=src /usr/local/anaconda3/envs/dads-crnn/bin/python \
  -m dads_crnn.audit_experiment_delta --mode verify
```

然后运行：

```bash
PYTHONPATH=src /usr/local/anaconda3/envs/dads-crnn/bin/python \
  -m dads_crnn.gate_candidate \
  --config configs/g4_low_snr_guardrails.yaml \
  --stage internal
```

最低要求：

| 指标 | 最低要求 |
|---|---:|
| DADS Val F1 | G2 − 0.002 |
| DADS Val AUC | G2 − 0.001 |
| DADS Test F1 | G2 − 0.002，即约0.99322 |
| DADS Test Recall | 0.990 |
| DADS Test Specificity | 0.990 |
| DADS Test AUC | 0.995 |

第一关失败立即保留G2，不运行val_ood。

### 6.2 第二关：val_ood冻结评估

只有第一关通过才运行：

```bash
nohup env PYTHONPATH=src CUDA_VISIBLE_DEVICES=0 \
  /usr/local/anaconda3/envs/dads-crnn/bin/python -u -m dads_crnn.calibrate_ood \
  --checkpoint archive/historical_models/failed_candidates/artifacts_crnn_full_augmented_g4_low_snr/runs/seed_42/best.pt \
  --tune-manifest artifacts/val_ood/manifests/val_ood_tune_manifest.csv \
  --holdout-manifest artifacts/val_ood/manifests/val_ood_holdout_manifest.csv \
  --output-dir artifacts/val_ood \
  --experiment crnn_full_augmented_g4_low_snr \
  --batch-size 256 --num-workers 0 --device auto \
  --target-recall 0.80 --target-specificity 0.90 \
  > logs/g4_crnn_full_seed42_val_ood.log 2>&1 &
echo $!
```

完成后执行严格晋级：

```bash
PYTHONPATH=src /usr/local/anaconda3/envs/dads-crnn/bin/python \
  -m dads_crnn.gate_candidate \
  --config configs/g4_low_snr_guardrails.yaml \
  --stage final
```

G4必须同时满足：

1. holdout F1、Balanced Accuracy、Recall、Specificity、AUC均不低于G2；
2. Recall至少提高0.03，或AUC至少提高0.02；
3. `-10 dB` Recall至少提高0.03；
4. DADS内部保护仍通过。

任一失败，门控输出`keep_g2`。只有全部通过才输出`promote_g4`。输出写入：

```text
artifacts/g4_low_snr/gate.json
artifacts/g4_low_snr/gate.md
```

Recall达到0.80且Specificity达到0.90，同时tune约束可行时，才额外标记为部署门槛通过。

## 8. Seed 42实测与最终判定（2026-07-17）

G4在epoch 38早停，最佳checkpoint为epoch 28，总耗时96.39分钟。第一关DADS内部保护通过：

| 指标 | G2 | G4 | 差值 |
|---|---:|---:|---:|
| Val F1 | 0.995003 | 0.995054 | +0.000051 |
| Test F1 | 0.995222 | 0.995254 | +0.000033 |
| Test Recall | 0.994673 | 0.993828 | -0.000845 |
| Test Specificity | 0.993840 | 0.995179 | +0.001339 |
| Test AUC | 0.999696 | 0.999590 | -0.000106 |

G2的四个保护文件SHA256复核一致，因此允许进入val_ood。冻结评估结果：

| 指标 | G2 | G4 | 差值 | 严格非劣通过 |
|---|---:|---:|---:|---:|
| F1 | 0.709546 | 0.682561 | -0.026985 | 否 |
| Balanced Accuracy | 0.708837 | 0.683662 | -0.025175 | 否 |
| Recall | 0.717808 | 0.686301 | -0.031507 | 否 |
| Specificity | 0.699865 | 0.681023 | -0.018843 | 否 |
| AUC | 0.760722 | 0.739201 | -0.021521 | 否 |

目标子组`-10 dB` Recall由0.629630提高到0.675926（+0.046296），超过预设的3个百分点要求；`-5/-15 dB`也分别提高3.96和6.12个百分点。但UAV-only、`+5 dB`和`+10 dB`分别下降11.67、8.74和12.62个百分点，背景Specificity下降1.88个百分点。说明微量低SNR训练确实改善了目标困难条件，却造成明显条件间权衡，不能作为整体更优模型。

最终机器判定为`keep_g2`：G4不晋级、不运行seed 43/44、不运行Unseen或Real-world。G2继续作为当前champion。完整判定见`artifacts/g4_low_snr/gate.md`。
