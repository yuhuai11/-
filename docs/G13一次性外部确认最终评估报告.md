# G13 一次性外部确认最终评估报告

## 摘要

本报告记录 ABDDV-CRNN 工程 G13 一次性外部确认评估的最终结果。评估严格按照事先冻结的协议执行，在全新的真实外部数据上比较 G7 基线和 G12 严格候选。

最终决策为：

> **`do_not_promote`：不晋级 G12 严格候选，严格模式继续保留 G7。**

G12 候选在六项预先冻结的晋级指标上全部劣于 G7，包括总体 FPR、总体 TPR、F1、背景来源宏平均 FPR、UAV 来源宏平均 TPR和低 FPR pAUC。候选的 ROC-AUC 和 PR-AUC 同样下降，表明问题不是单纯由固定阈值造成，而是候选模型在新外部域上的分数排序和泛化能力整体弱于 G7。

G13 已完成唯一一次正式评估，现已被消费。不得在 G13 上重新调整阈值、温度、模型、数据处理或训练方案后再次测试。

## 1. 评估目的

G13 的目标不是继续优化模型，而是对已经冻结的严格模式候选进行独立外部确认：

1. 检验 G9 困难负类适配及三种子集成能否迁移到新的真实背景；
2. 检验候选对新的真实 UAV 录音是否保持或提高召回；
3. 检验候选在低误报工作区间内是否优于 G7；
4. 在完全不利用 G13 调参的条件下决定严格模式是否晋级。

平衡模式不参与本次晋级，继续保留 G7。

## 9. 结论分析

### 9.1 当前方向的有效部分

G9/G12 方向在方法上仍有合理之处：

- 使用困难负类针对误报问题进行适配；
- 使用三个随机种子降低单模型方差；
- 在 tune 数据上独立冻结温度和严格阈值；
- 使用来源稳健门槛而非只看总体准确率；
- 使用一次性外部确认集避免测试集反复调参。

这些实验控制措施保证了本次负面结论具有可信度。

### 9.2 失败原因指向

G13 结果支持以下判断：

1. **困难负类适配存在来源特异性。**  
   G9 使用的困难负类改善没有迁移到 AeroSonicDB 的新录音会话。

2. **候选对新 UAV 域的表示能力下降。**  
   MINI、PRO4 以及 UAV 来源宏平均 TPR 均下降，说明优化背景误报时损失了部分 UAV 泛化能力。

3. **问题不只是阈值校准。**  
   ROC-AUC、PR-AUC 和低 FPR pAUC 全面下降，表示候选的分数排序本身变差。

4. **三模型集成没有抵消域偏移。**  
   多种子平均可以降低随机训练波动，但无法解决训练困难负类与新外部来源之间的系统性域差异。

5. **G7 的广泛预训练表示更稳健。**  
   在全新真实域上，较少针对性适配的 G7 反而同时获得更低 FPR 和更高 TPR。

### 9.3 可以确定的部署结论

- 严格模式继续使用 G7；
- 平衡模式继续使用 G7；
- 不部署 G12候选；
- 不通过降低 G12 阈值来恢复 TPR，因为其 FPR 已经更高；
- 不通过提高 G12 阈值来降低 FPR，因为其 TPR 已经更低；
- 不在 G13 上搜索新阈值或集成权重。

## 10. 后续研究建议

G13 只能用于得出本次最终结论，不能再参与开发。后续实验必须使用新的开发数据，并预留另一个从未读取的最终确认集。

建议下一阶段优先级如下：

1. **暂时停止继续堆叠相同来源的困难负类。**  
   当前瓶颈已经从训练集误报转为跨设备、跨会话和跨录音域泛化。

2. **建立多来源开发集。**  
   使用与 G13 不重叠的新背景和 UAV 数据，按数据集、设备或录音会话划分训练、校准和验证来源。

3. **研究域泛化而非单纯阈值优化。**  
   可考虑来源均衡采样、域不变表示、频谱扰动、设备响应模拟和多环境混响，但必须在新的开发验证集上评估。

4. **保留广泛预训练能力。**  
   后续适配应采用更小学习率、部分层冻结、正则化或参数高效适配，降低对 G7 通用表示的破坏。

5. **将来源宏指标纳入训练期验证。**  
   模型选择不能只依据样本级 loss 或 F1，应同时约束背景来源宏 FPR 与 UAV 来源宏 TPR。

6. **建立新的最终确认集。**  
   新方案完成开发后，必须使用未参与任何分析和选择的新数据进行一次性确认，不能复用 G13 作为最终门槛。
