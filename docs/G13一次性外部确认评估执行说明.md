# G13 一次性外部确认评估执行说明

## 1. 目标

G13 只用于一次性比较两个已经冻结的严格模式系统：

- 基线：G7 PANNs Cnn14_16k，固定温度与固定严格阈值；
- 候选：G9 seed 42、43、44 的 raw-logit 算术平均，复用 G10 温度与 G12 严格阈值。

G13 不用于重新训练、筛选检查点、拟合温度或调整阈值。平衡工作模式始终保留 G7。

## 2. 冻结值

冻结程序从已有产物解析并校验以下值，而不是接受命令行覆盖：

| 项目 | 冻结值 |
|---|---:|
| G7 温度 | 2.258312527893372 |
| G7 严格阈值 | 0.7236399840238329 |
| G12 候选温度 | 2.242371986350744 |
| G12 候选严格阈值 | 0.7088954330786355 |
| 候选集成 | seed 42/43/44 raw-logit 算术平均 |

冻结文件还绑定配置、协议、G13 intake audit、G13 manifest、来源登记表、四个模型检查点、G7/G12 校准产物和评估器源码的 SHA256。

## 3. 三阶段执行

### 3.1 冻结

```bash
cd /home/user1/JJZ/ABDDV-CRNN
bash scripts/run_g13_confirmation.sh freeze \
  2>&1 | tee logs/g13_freeze.log
```

该步骤读取元数据与文件哈希，不读取 G13 音频，不生成 G13 模型预测。成功后生成：

```text
artifacts/g13_external_confirmation/evaluation/frozen_protocol.json
```

冻结后不得修改 G13 评估配置、协议文件、评估器源码、模型或校准产物。

### 3.2 非 G13 预检

建议先将 RTX 3080 功耗限制为 250 W：

```bash
sudo nvidia-smi -pl 250
```

然后运行：

```bash
cd /home/user1/JJZ/ABDDV-CRNN
bash scripts/run_g13_confirmation.sh preflight \
  2>&1 | tee logs/g13_preflight.log
```

预检依次严格加载 G7 和三个 G9 检查点，只对内存中构造的 1 秒零波形做推理。它不会打开 G13 manifest 中的音频路径。

预检必须满足：

- 四个模型均能严格加载；
- 四个输出均为有限值；
- 三模型 raw-logit 平均及温度变换结果为有限值；
- 预检记录绑定当前冻结协议哈希。

### 3.3 唯一一次正式推理

只有确认冻结和预检均通过后才执行：

```bash
cd /home/user1/JJZ/ABDDV-CRNN
G13_CONFIRM_ONCE=YES nohup bash scripts/run_g13_confirmation.sh evaluate \
  > logs/g13_final_once.log 2>&1 &
echo $!
```

实时查看清洗后的进度：

```bash
tail -F logs/g13_final_once.log | tr '\r' '\n'
```

另开一个 VS Code SSH 终端监控 GPU：

```bash
watch -n 5 'nvidia-smi --query-gpu=timestamp,temperature.gpu,utilization.gpu,memory.used,memory.total,power.draw --format=csv,noheader'
```

查看进程：

```bash
pgrep -af 'evaluate_g13_confirmation|run_g13_confirmation'
```

## 4. 中断恢复

正式任务按模型保存原子缓存。SSH 断开不会影响 `nohup` 任务。若系统重启或进程异常退出，可使用完全相同的正式命令恢复；程序会校验冻结协议、manifest 和检查点 SHA256 后，仅复用身份完全一致的缓存。

技术恢复不得修改以下任何项目：

- 配置、协议或评估源码；
- 模型检查点；
- G13 manifest 或来源登记表；
- 温度、阈值、批量大小或指标门槛。

一旦生成最终 `metrics.json`，程序拒绝任何再次执行。

## 5. 输出

```text
artifacts/g13_external_confirmation/evaluation/final_once/
├── FINAL_TEST_UNLOCKED.json
├── cache/
│   ├── g7.npz
│   ├── g9_seed_42.npz
│   ├── g9_seed_43.npz
│   └── g9_seed_44.npz
├── predictions.csv
└── metrics.json
```

`predictions.csv` 保存四个模型的原始 logit、两套校准概率和固定阈值预测，便于审计，但不得据此重新调参。

## 6. 唯一晋级规则

候选必须同时满足：

1. 总体 FPR 不高于 G7；
2. 总体 TPR 不低于 G7；
3. 总体 F1 不低于 G7；
4. 29 个背景来源的宏平均 FPR 不高于 G7；
5. 29 个 UAV 来源的宏平均 TPR 不低于 G7；
6. `FPR ≤ 0.05` 的标准化 pAUC 不低于 G7。

全部通过输出 `promote_strict_candidate`；任意一项失败输出 `do_not_promote` 并保留 G7。准确率仅作为描述指标，不参与晋级。

## 7. 数据解释注意事项

- G13 类别比例为 49,612 个背景和 5,388 个 UAV，不能用总体准确率主导结论；
- AeroSonicDB 的 `aircraft` 是关键困难负类，应与 `urban_silence` 分开报告；
- DDL 的 `MINI` 与 `PRO4` 应分开报告；
- 连续切片存在来源内相关性，因此同时报告来源宏平均与来源组聚类 Bootstrap；
- AeroSonicDB 采用 CC BY-NC 4.0，仅可用于非商业研究场景。
