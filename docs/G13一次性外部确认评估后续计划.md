## 四、阶段二：唯一一次正式推理

### 4.1 启动条件

只有同时满足以下条件才允许启动：

- GPU 预检显示 `passed=true`；
- 预检设备为 `cuda`；
- 冻结协议、模型、配置和数据清单没有变化；
- `metrics.json` 尚不存在；
- 没有另一个 G13 正式评估进程正在运行。

启动前检查进程：

```bash
pgrep -af 'evaluate_g13_confirmation|run_g13_confirmation'
```

### 4.2 启动命令

```bash
cd /home/user1/JJZ/ABDDV-CRNN
mkdir -p logs

G13_CONFIRM_ONCE=YES nohup bash scripts/run_g13_confirmation.sh evaluate \
  > logs/g13_final_once.log 2>&1 &

echo $!
```

该命令将 G13 标记为已解锁并开始读取 55,000 条确认集音频。正式推理一旦开始，G13 即视为已经消费。

### 4.3 推理顺序

统一评估器依次执行：

1. 校验冻结协议及全部输入 SHA256；
2. 校验 G13 manifest 的行数、标签数、唯一哈希数和来源组数；
3. 生成 G7 的 55,000 条 raw logits；
4. 生成 G9 seed 42 的 55,000 条 raw logits；
5. 生成 G9 seed 43 的 55,000 条 raw logits；
6. 生成 G9 seed 44 的 55,000 条 raw logits；
7. 计算三个 G9 模型的 raw-logit 算术平均；
8. 应用冻结温度和冻结阈值；
9. 生成逐样本预测文件；
10. 计算总体、来源组、条件和低 FPR 指标；
11. 根据六项固定门槛生成最终决策。

## 六、阶段四：中断与恢复

### 6.1 SSH 或 VS Code 断开

正式任务由 `nohup` 在后台运行，SSH 或 VS Code 断开通常不会终止任务。重新连接后执行：

```bash
cd /home/user1/JJZ/ABDDV-CRNN
pgrep -af 'evaluate_g13_confirmation|run_g13_confirmation'
tail -n 50 logs/g13_final_once.log
```

### 6.2 系统重启或进程异常退出

评估器在每个模型完成后原子保存预测缓存。若系统重启或进程异常退出，可使用完全相同的正式命令恢复：

```bash
cd /home/user1/JJZ/ABDDV-CRNN

G13_CONFIRM_ONCE=YES nohup bash scripts/run_g13_confirmation.sh evaluate \
  >> logs/g13_final_once.log 2>&1 &

echo $!
```

程序只会复用 manifest SHA256 和 checkpoint SHA256 都完全一致的缓存。

### 6.3 禁止操作

技术恢复期间禁止：

- 修改评估配置或评估源码；
- 修改模型检查点；
- 修改 G13 manifest、音频或来源登记表；
- 更换温度或阈值；
- 根据部分预测结果重新训练或挑选模型；
- 删除或人工修改已经生成的模型缓存；
- 并行启动两个正式评估进程。

## 七、阶段五：固定评估指标

### 7.1 总体指标

对 G7 和 G12 候选分别计算：

- TP、FP、TN、FN；
- FPR；
- TPR/Recall；
- Precision；
- F1；
- Specificity；
- Balanced Accuracy；
- ROC-AUC；
- PR-AUC；
- `FPR ≤ 0.05` 标准化 pAUC。

由于 G13 类别不平衡，总体 Accuracy 不参与晋级判断。

### 7.2 不确定性

- 总体 TPR：Clopper-Pearson 95% 置信区间；
- 总体 FPR：Clopper-Pearson 95% 置信区间；
- 主要阈值指标：按来源组进行聚类 Bootstrap；
- 来源宏平均指标：按来源组 Bootstrap。

### 7.3 来源组指标

- 29 个 AeroSonicDB 背景来源组的宏平均 FPR；
- 29 个 DDL UAV 来源组的宏平均 TPR；
- 最差来源表现；
- 每个来源组的样本量、误报数或漏报数。

### 7.4 条件指标

背景条件：

- `urban_silence`；
- `aircraft`。

UAV 条件：

- `MINI`；
- `PRO4`。

其中 `aircraft` 是最重要的困难背景条件，应单独分析其误报率。

## 八、阶段六：唯一晋级门槛

G12 严格候选必须同时满足：

| 指标 | 晋级条件 |
|---|---|
| 总体 FPR | 不高于 G7 |
| 总体 TPR | 不低于 G7 |
| 总体 F1 | 不低于 G7 |
| 背景来源宏平均 FPR | 不高于 G7 |
| UAV 来源宏平均 TPR | 不低于 G7 |
| `FPR ≤ 0.05` 标准化 pAUC | 不低于 G7 |

决策规则：

- 六项全部通过：`promote_strict_candidate`；
- 任意一项失败：`do_not_promote`；
- 无论结果如何，平衡模式继续使用 G7；
- 不允许在同一 G13 数据集上调参后重试。
