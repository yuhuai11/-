# 声学无人机检测与开放集型号识别系统：外部泛化测试方案

## 1. 目的

本方案用于评估当前已训练模型从 DADS 内部分布迁移到新无人机、新背景和真实录音时的泛化能力。评估期间冻结模型、特征参数和阈值；外部数据不参与训练、early stopping、阈值选择或概率校准。

## 2. 外部数据

| 名称 | 正类 | 负类 | 采样率 | 时长 | 用途 |
|---|---:|---:|---:|---:|---|
| `unseen` | 25,620 | 25,620 | 44.1 kHz | 约 1 秒 | 新无人机、新背景和混合条件 |
| `real_world` | 273 | 273 | 44.1 kHz | 约 1 秒 | 真实交通、直升机等干扰 |

数据路径集中定义在 `configs/external_evaluation.yaml`。测试代码只读源 WAV，不把它们写入训练缓存。

## 3. 冻结模型矩阵

评估五个实验组的 seed 42、43、44：

1. CRNN，5000/类；
2. CRNN，15000/类；
3. CRNN，全量；
4. ResNet10-CBAM，15000/类；
5. ResNet10-CBAM，全量。

主结论优先比较两个全量模型；不同训练规模只用于分析数据规模效应。

## 4. 输入与阈值

所有 WAV 使用当前工程的音频代码执行：mono float32、重采样至 16 kHz、确定性裁剪或循环补齐至 1 秒、峰值归一化。特征和模型结构直接读取检查点中的原始配置：CRNN 使用 Log-Mel，ResNet10-CBAM 使用 MFCC。

主阈值固定为 `0.50`，同时报告 `0.40/0.50/0.65` 敏感性结果。不得根据外部测试结果新增或修改阈值。

## 5. 指标与统计

每个数据集、模型、随机种子和阈值记录 Accuracy、Balanced Accuracy、Precision、Recall、Specificity、FPR、F1、ROC-AUC、PR-AUC 和混淆矩阵。主阈值额外计算按标签分层、按 SHA256 音频身份成组抽样的 bootstrap 95% 置信区间，避免重复音频让区间虚假变窄。

跨三个随机种子报告均值和样本标准差，并计算：

```text
generalization gap = external metric - DADS internal test metric
retention = external metric / DADS internal test metric
```

Real-world 必须同时解释 Recall 和 Specificity，不能以几乎全部预测为 UAV 换取高 Recall。

## 6. 分组失效分析

- `unseen`：按文件名解析无人机/背景来源及 T01～T10 条件；
- `real_world`：按 traffic、helicopter 和 other 条件分组；
- 每组记录样本数、平均 UAV 概率、Accuracy、Recall/Specificity、FP 和 FN。

逐样本概率保留在 `predictions.csv`，后续可以定位高置信度错误，但不能用这些样本回调当前最终测试结果。

## 7. 数据审计

正式运行时生成不可变 manifest，记录路径、标签、来源分组、采样率、时长和可选 SHA256。启用完整审计后，还会将外部 WAV 与 DADS parquet 内原始 WAV 字节进行精确哈希比对。

精确哈希只能发现完全相同文件；来源级或经过重编码的近重复仍需要后续音频指纹审计。发现重复时保留原始结果，并另外报告去重口径。

## 9. 运行流程

### 9.1 生成正式 manifest 与精确重复审计

```bash
PYTHONPATH=src python -m dads_crnn.prepare_external_manifests \
  --config configs/external_evaluation.yaml \
  --hash-files \
  --dads-parquet-dir date/DADS/data
```

若只做快速结构检查，可以省略 `--hash-files --dads-parquet-dir ...`。

### 9.2 预览完整评估矩阵

```bash
PYTHONPATH=src python -m dads_crnn.run_external_suite \
  --config configs/external_evaluation.yaml \
  --dry-run
```

### 9.3 正式运行

建议先运行全量模型：

```bash
PYTHONPATH=src python -m dads_crnn.run_external_suite \
  --config configs/external_evaluation.yaml \
  --experiments crnn_full resnet10_cbam_full
```

确认主评估完成后，再运行其余数据规模：

```bash
PYTHONPATH=src python -m dads_crnn.run_external_suite \
  --config configs/external_evaluation.yaml \
  --experiments crnn_5000 crnn_15000 resnet10_cbam_15000
```

### 9.4 汇总

```bash
PYTHONPATH=src python -m dads_crnn.summarize_external
```

## 10. 实验纪律

Unseen 与 Real-world 从首次正式运行起视为锁定的最终测试集。外部结果可以用于失效分析，但后续模型训练和选择必须建立独立 `val_ood`；不得反复根据这两套测试结果调整增强、结构或阈值后再宣称无偏提升。
