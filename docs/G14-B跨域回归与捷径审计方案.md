# G14-B跨域回归与捷径审计方案

## 1. 目的

G14-A三个随机种子的仅分类头适配已经完成，但Kielce只提供正类、TAU只提供负类，
因此“数据集来源”和“类别标签”完全相关。G14开发留出集接近满分不能单独证明模型
学习的是无人机声学特征，也可能包含录音设备、压缩、地点或数据集制作流程指纹。

G14-B不训练、不修改模型，只比较锁定G7基线与G14-A三个检查点在既有开发数据上的
行为，回答两个问题：

1. G14-A是否破坏原有DADS与val_ood能力；
2. G14-A是否增加飞机、直升机、链锯、割草机、发动机和火车等硬负样本误报。

G13外部确认数据已经消费并封存，本阶段禁止读取。

## 2. 固定输入

- 基线：G7 seed 42，SHA256
  `d357f194105ec27a61838e0f4c2e7575932e2dd861e529ef970b1fb467954cdc`；
- 候选：G14-A seed 42、43、44的最佳检查点；
- DADS：锁定`test`划分，共45,891个片段；
- val_ood：tune 1,527条、holdout 1,473条；
- G9 guard：ESC-50 fold 5六类硬负样本，共240个片段。

所有清单、基线预测、候选检查点和G9审计均进行SHA256绑定。输出只能写入
`artifacts/g14_domain_generalization/regression`。

## 3. 回归门槛

每个随机种子都必须通过：

- DADS test F1相对G7下降不超过0.005；
- DADS test AUC相对G7下降不超过0.002；
- val_ood holdout F1相对G7下降不超过0.02；
- val_ood holdout AUC相对G7下降不超过0.01；
- G9 guard在阈值0.5的片段假阳性率增量不超过0.01。

任何一个seed失败即拒绝G14-A作为替代模型。全部通过也只允许继续受控开发，
不能晋升为最终模型，因为Kielce/TAU的标签—数据集混杂仍需反事实控制。

## 4. 已完成预检

预检已经验证三个候选、五份基线预测/标签、三类评估清单和G9审计的身份；报告明确
记录`dataset_label_confounding: true`、`locked_datasets_read: []`、
`training_started: false`及`model_parameters_updated: false`。

预检证据：

## 6. 正式结果

G14-B已经完成，三个seed均未通过固定阈值回归门控，决策为
`reject_g14_head_only_due_to_regression`。

在阈值0.5下，G7基线的DADS test F1为0.996992、特异性为0.993305；G14三个seed
的F1为0.986019至0.986395，下降0.01060至0.01097，特异性下降约0.0318至0.0329。
G9 guard片段假阳性率由0.0625升至0.1333至0.1375，明显超过允许的0.0725上限。
增长集中在链锯（0.075升至0.275）、发动机（0.05升至0.15）、吸尘器
（均值约0.0833）和洗衣机（0.225升至0.30）；飞机和直升机没有新增误报。

另一方面，val_ood holdout F1由0.54113提升至0.62697至0.63176，AUC由0.79162
提升至0.80535至0.80613；DADS AUC只下降约0.00009。这说明排序能力没有明显损坏，
主要问题是仅分类头适配使输出整体偏向正类。下一步只允许使用DADS val、
val_ood tune和G14 tune预注册统一阈值，不得用DADS test、val_ood holdout或
G9 guard选阈值。若调参集选出的阈值仍不能同时通过原门控，则终止G14-A路线并回到
数据级反事实控制，不得通过放宽门槛晋级。
