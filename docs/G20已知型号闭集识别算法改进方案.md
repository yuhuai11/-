# G20已知型号闭集识别算法改进方案

## 1. 目标与边界

G20只研究Kielce九个已知无人机型号的录音级闭集分类，不研究未知型号拒识。

- 优化输入：`known_train`
- 选模输入：`known_tune`
- 不读取：`unknown_tune`、Known/Unknown Holdout、X6D、Y6
- 冻结并复用经过身份校验的G7 2048维片段特征
- 新产物写入`artifacts/g20_closed_set_multiscale/`，不覆盖G19

因此，G20只能回答“输入已知属于九类之一时，具体型号识别是否更好”，不能回答未知型号
能否被拒绝。

## 2. 为什么需要改进

G19在`known_tune`上达到95.60% Accuracy、94.78% Macro-F1和85.71%最低类别
Recall，但注意力的平均标准化熵为0.99835。熵接近1表示各片段权重近似均匀，原本设计
的学习型录音聚合实际上退化得接近Logit/特征平均。

G20针对这一可观测问题进行独立实验，不事后修改G19方法或结果。

## 3. 算法变化

### 3.1 多头注意力统计池化

G19用一个注意力头计算加权均值。G20使用4个注意力头，每个头同时计算：

- 加权均值：表示整条录音的稳定型号特征；
- 加权标准差：表示片段间旋翼、转速和噪声变化。

四组均值与标准差拼接后，再投影成128维录音Embedding。多头机制允许不同头关注不同
声学片段，统计池化则保留均值池化会丢失的时变信息。

### 3.2 片段级辅助监督

除录音级分类损失外，每个有效1秒片段也接受所属型号的辅助交叉熵监督。它不改变最终
评价单位，最终指标仍然严格按原始录音计算。作用是让投影器先学到片段级可分类证据，
再由注意力聚合器学习如何组合。

### 3.3 注意力多样性和聚焦约束

- 多样性损失降低不同注意力头之间的余弦相似度，避免4个头学习成同一个头；
- 聚焦损失只惩罚高于0.85的标准化注意力熵，避免再次退化为均匀平均；
- 约束权重较小，主目标仍然是录音级正确分类。

### 3.4 余弦分类器

分类器对录音Embedding和类别权重进行L2归一化，再用可学习尺度计算Logit。这样减少
向量模长对预测的干扰，使分类更直接地依赖类别方向和角度间隔。

### 3.5 完整训练目标

```text
L = L_recording_CE
  + 0.15 L_SupCon
  + 0.20 L_segment_CE
  + 0.05 L_attention_diversity
  + 0.02 L_attention_focus
```

训练使用3轮线性预热和余弦学习率衰减；模型选择仍优先Macro-F1，再比较最低类别Recall。

## 4. 公平比较

G20与G19使用相同的`known_train`、`known_tune`、冻结G7特征和seed 42。主要比较：

| 指标 | G19基线 | G20目标门槛 |
|---|---:|---:|
| Accuracy | 0.9560 | ≥0.9500 |
| Macro-F1 | 0.9478 | ≥0.9400 |
| 最低类别Recall | 0.8571 | ≥0.8500 |
| 注意力熵 | 0.9984 | 观察是否显著下降 |

门槛用于防止新结构损害现有识别能力；只有运行后才能判断是否真正改进，不能把架构变化
本身称为性能提升。由于G19已使用`known_tune`选模，G20结果也是开发集对比，不是新的
独立最终测试结论。
