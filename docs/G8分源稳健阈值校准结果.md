损失超过冻结保护线；1%工作点的实际FPR也仍略高于2%上限。因此不运行seed 43/44，
不解锁Unseen或Real-world，也不根据holdout结果回调阈值。

## 4. 原因定位

两个工作点均由同一困难来源决定：

```text
github_U17_helicopter/HELICOPTER_013.wav
```

该来源在1%工作点的最大负类分数为0.811647；在5%工作点允许1个误报时，第二个尾部
边界仍达到0.789001。其后依次是`BACKGROUND_010`、`HELICOPTER_028`和
`HELICOPTER_006`。这说明主要瓶颈不是普通概率温度或pooled样本权重，而是PANNs把
若干旋翼/直升机背景赋予了与无人机高度重叠的分数。

G8也证明仅提高阈值不能同时满足低误报和高召回：排序虽然优于G2和Scratch，但困难
负类仍位于ROC左端关键区域。继续尝试不同分位数只会在已查看的holdout上调参，不能
形成可信进步。

## 5. 后续方向

下一阶段应从“阈值优化”转为“训练期困难负类分离”，保留G7-PT骨干：

1. 只在训练池中引入与val_ood来源、路径及SHA256完全隔离的旋翼类困难负样本；
2. 对直升机、风扇、割草机等周期性机械声采用来源均衡采样；
3. 首先比较普通BCE与低误报导向的非对称困难负类损失，每次只改变一个因素；
4. DADS内部F1、Recall、Specificity继续执行非劣保护；
5. `val_ood tune`只用于冻结阈值，不把其片段加入训练；
6. 由于现有holdout已用于多轮开发，最终结论必须使用新的来源隔离确认集。

这一路线可命名为G9“来源隔离困难负类适配”。G8及原G7结果全部保留，不覆盖冠军
G2，也不把失败的阈值方案包装为优化成功。
