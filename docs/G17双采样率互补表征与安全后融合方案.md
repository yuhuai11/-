# G17双采样率互补表征与安全后融合方案

## 1. 文档目的

本文档将 Casabianca 和 Zhang（2021）《Acoustic-Based UAV Detection Using Late
Fusion of Deep Neural Networks》中可迁移的思想，转化为本声学无人机检测与开放集
型号识别工程后续可执行、
可审计的改进方案。

本方案的目标不是复现论文的测试高分，也不使用已消费的 Unseen 数据进行针对性训练，
而是在保留正式 G7 模型能力的前提下，引入高采样率互补声学表征和安全后融合，提高：

- 新机型检测能力；
- 跨设备、跨来源泛化能力；
- 低信噪比 UAV Recall；
- 固定低 FPR 下的 TPR；
- 最差 UAV 来源性能。

阶段名称：

```text
G17：双采样率互补表征与安全后融合
```

G17是开发阶段候选方案，不自动替代正式G7。

## 3. 论文思想的适用性分析

参考论文：

```text
Casabianca, P.; Zhang, Y. (2021)
Acoustic-Based UAV Detection Using Late Fusion of Deep Neural Networks
```

论文可借鉴的核心思想：

1. 使用多机型 UAV 音频，学习一般旋翼声学特征；
2. 将 UAV 与多种背景动态组合，覆盖不同检测难度；
3. 保留 44.1 kHz 输入中的高频信息；
4. 使用多个互补模型进行 Late Fusion；
5. 通过融合降低单模型随机波动。

不能直接照搬的部分：

- 不把人工混合集等同于真实最终测试集；
- 不使用 Unseen、Real-world 或 G13 训练、校准或选择模型；
- 不按1秒切片后再随机划分来源相关片段；
- 不只用Accuracy确定模型或融合权重；
- 不立即训练10个高度相似的CNN；
- 不针对已经查看过的测试结果反复调参后声称无偏提升。

## 4. 总体技术路线

G17采用两个互补分支：

```text
                         ┌────────────────────────────┐
原始音频 → 16 kHz波形 → │ G7 PANNs Cnn14_16k       │ → G7 Logit
                         └────────────────────────────┘
                                      │
                                      ├─ 受约束Logit融合 → 概率校准 → 双工作阈值
                                      │
                         ┌────────────────────────────┐
原始音频 → 44.1/48 kHz →│ 轻量高频Log-Mel CNN      │ → 高频Logit
                         └────────────────────────────┘
```

分支职责：

| 分支 | 主要作用 |
|---|---|
| G7 16 kHz分支 | 保留AudioSet预训练、DADS内部能力和宽泛声学识别能力 |
| 高频辅助分支 | 补充8 kHz以上谐波、设备频响和新机型旋翼声纹 |
| 后融合模块 | 在不修改G7检查点的情况下利用两个分支的互补证据 |

G7始终保留为可回退的正式模型。

### 5.2 禁止用于开发

以下数据已经被消费，只允许读取冻结指标、预测和归档元数据：

```text
Unseen
Real-world
G13一次性外部确认集
```

禁止：

- 读取其原始音频进行特征分析；
- 将其片段加入训练；
- 根据其结果调整增强、损失、解冻范围、融合权重或阈值；
- 再次把它们称为新模型的无偏最终测试集。

### 5.3 划分和去重要求

必须先按以下层级划分，再生成1秒片段：

```text
原始音频SHA256
→ recording_group
→ source_group
→ 机型/设备/场景来源
→ Train/Tune/Holdout
→ 片段生成
```

门控要求：

- Train、Tune、Holdout原始音频SHA256交集为0；
- recording_group交集为0；
- source_path交集为0；
- 同一无人机录音的相邻片段不得跨划分；
- 训练集与已消费外部数据音频哈希交集为0。

## 6. G17-P0：高频可行性审计

P0只做审计，不训练模型、不写检查点。

### 6.1 审计内容

对允许开发的数据统计：

- 原始采样率；
- 位深和通道数；
- 是否存在伪上采样；
- 0～8 kHz、8～12 kHz、12～16 kHz、16～20 kHz能量占比；
- UAV与背景在高频频段的可分性；
- 设备与来源对高频能量的影响；
- 音频SHA256重复；
- 来源隔离情况；
- 数据许可和可复现路径。

### 6.2 高频有效性判定

至少满足以下条件才进入P1：

1. 允许训练的UAV数据中存在真实高于8 kHz的有效信息；
2. 不是由16 kHz音频重新上采样产生；
3. 高频能量差异不完全由单一设备或单一来源决定；
4. Train与开发集完成来源隔离；
5. 高频分支的输入不需要读取任何已锁定数据。

如果高频信息不足：

```text
decision = terminate_high_rate_branch
```

此时不构建高频模型，转向G7高层受控解冻方案。

### 6.3 P0输出

建议输出：

```text
artifacts/g17_dual_rate/p0_audit/audio_inventory.csv
artifacts/g17_dual_rate/p0_audit/spectral_band_summary.csv
artifacts/g17_dual_rate/p0_audit/source_overlap_audit.json
artifacts/g17_dual_rate/p0_audit/decision.json
```

## 7. G17-P1：高频辅助分支

### 7.1 输入参数

初始建议：

| 参数 | 设置 |
|---|---:|
| Sample rate | 保持44.1 kHz，必要时统一至48 kHz |
| Segment | 1秒 |
| FFT window | 2048 |
| Hop | 441或480采样点，约10 ms |
| Mel bins | 96 |
| Minimum frequency | 50 Hz |
| Maximum frequency | 20 kHz |
| 输入归一化 | 保留相对能量，避免无条件逐片段峰值归一化 |

是否采用44.1或48 kHz必须由P0原始采样率审计决定，不允许仅为了统一格式进行无意义
伪上采样。

### 7.2 初始模型

先使用轻量CNN，而不是复制完整PANNs Cnn14：

```text
Log-Mel
→ Conv Block 1
→ Conv Block 2
→ Conv Block 3
→ Conv Block 4
→ Frequency Attention
→ Temporal Mean + Max Pool
→ FC
→ Binary Logit
```

目标：

- 模型参数控制在约5M～15M；
- RTX 3080能够稳定训练；
- 与G7错误具有互补性；
- 不以单模型绝对高分作为唯一目标。

### 7.3 Batch来源组成

建议Batch size 128：

| 来源 | 数量 |
|---|---:|
| DADS正类 | 30 |
| DADS背景 | 30 |
| Kielce UAV | 28 |
| Kielce UAV与TAU动态混合 | 24 |
| G9机械困难负类 | 8 |
| TAU纯背景 | 8 |

实际数量可以根据可用来源调整，但每个Batch必须记录：

- 来源计数；
- 标签计数；
- UAV机型计数；
- 动态混合SNR计数；
- 是否有放回采样。

### 7.4 动态混合SNR

初始权重：

| 目标SNR | 权重 |
|---:|---:|
| -15 dB | 0.05 |
| -10 dB | 0.15 |
| -5 dB | 0.25 |
| 0 dB | 0.25 |
| +5 dB | 0.20 |
| +10 dB | 0.10 |

低SNR混合样本控制在正类的30%～40%，避免极弱正标签主导训练。

### 7.5 其他增强

- 麦克风频率响应扰动；
- 轻度带通、低通和高频衰减；
- 录音增益变化；
- 轻度动态范围压缩；
- 轻度时间伸缩，模拟不同旋翼转速；
- 真实或受控卷积混响；
- 城市、交通、机械和航空器背景；
- 随机时间平移。

增强不得改变标签语义，并应记录随机参数以便复现。

## 8. G17-P2：独立分支评估与互补性分析

冻结高频分支后，分别生成以下预测：

```text
G7概率
高频分支概率
简单平均概率
待拟合融合概率
```

### 8.1 单模型指标

两个分支均报告：

- Accuracy；
- Balanced Accuracy；
- Precision；
- Recall；
- Specificity；
- FPR；
- F1；
- ROC-AUC；
- PR-AUC；
- 标准化pAUC（FPR≤0.05）；
- TPR@1% FPR；
- TPR@5% FPR；
- 来源宏平均Recall/FPR；
- 最差来源Recall/Specificity；
- 各SNR Recall。

### 8.2 错误互补性

必须统计：

| 情形 | 含义 |
|---|---|
| G7正确、高频分支错误 | 高频分支可能损害原能力 |
| G7错误、高频分支正确 | 高频分支提供有效互补 |
| 两者都正确 | 稳定区域 |
| 两者都错误 | 融合难以解决的共同盲区 |

推荐计算：

- 错误Jaccard相似度；
- 预测概率相关系数；
- 按来源的错误重叠；
- 按SNR的错误重叠；
- 配对McNemar检验；
- 配对Bootstrap置信区间。

如果高频分支与G7预测高度相关且没有提供新增正确样本：

```text
decision = terminate_no_complementarity
```

## 9. G17-P3：安全后融合

### 9.1 融合公式

首选Logit级线性融合：

```text
z_fused = w × z_g7 + (1 - w) × z_high_rate
p_fused = sigmoid(z_fused / T_fusion)
```

约束：

```text
0.5 ≤ w ≤ 1.0
```

保证G7占主要权重。

第一阶段只允许：

- 简单平均；
- 单参数受约束权重；
- 单温度校准。

暂不使用复杂MLP融合器，避免在小型Tune集上过拟合。

### 9.2 权重目标

不使用Accuracy直接确定权重。建议在Tune上求解：

```text
最大化：
  低FPR pAUC
  + 来源宏平均Recall
  + TPR@1% FPR
  + TPR@5% FPR

约束：
  DADS开发F1非劣
  DADS Specificity非劣
  背景宏平均FPR不超限
  最差来源Recall不下降
```

### 9.3 双工作模式

冻结两个阈值：

1. 严格低误报模式；
2. 平衡检出模式。

阈值只能由Tune确定。Holdout只运行一次，且不得根据Holdout结果继续调整融合权重、
温度或阈值。

## 10. G17-P4：受控解冻备选路径

如果P0证明高频信息不足，或者P2证明两个分支缺乏互补性，则进入受控解冻路径。

解冻范围：

| G7模块 | 状态 | 学习率建议 |
|---|---|---:|
| 二分类Head | 训练 | `1e-4` |
| `fc1` | 训练 | `2e-5` |
| `conv_block6` | 训练 | `5e-6` |
| 前五个Conv Block | 冻结 | 0 |
| BatchNorm运行统计 | 冻结 | 0 |

损失建议：

```text
L_total =
1.0 × 来源均衡BCE
+ 0.5 × 低SNR正类BCE
+ 0.5 × G7教师蒸馏
+ 0.1 × 来源内对比损失
```

不再以正负样本Pair Ranking作为主损失，因为G16已经显示排序改善并不保证低SNR绝对
检出概率提高。

受控解冻和高频分支不得在同一首轮实验中同时改变。必须保持单变量可解释性。

## 11. 统一评价协议

评价单位统一为1秒片段级，不以文件级平滑结果替代主结果。

所有候选报告：

| 类型 | 指标 |
|---|---|
| 阈值相关 | Accuracy、Balanced Accuracy、Precision、Recall、Specificity、FPR、F1、TP/FP/TN/FN |
| 阈值无关 | ROC-AUC、PR-AUC、标准化pAUC≤0.05 |
| 部署指标 | TPR@1% FPR、TPR@5% FPR、每小时误报数 |
| 稳健指标 | 来源宏平均、最差来源、SNR分组、设备分组 |
| 统计指标 | 多seed均值/标准差、配对Bootstrap、McNemar |
| 效率指标 | 参数量、显存、吞吐率、实时因子、推理延迟 |

评价口径必须与：

```text
docs/G7模型结果与性能分析报告.md
```

中的“内外部评价指标统一对齐”章节保持一致。

## 12. 晋级门槛

### 12.1 Seed 42可行性门槛

建议预注册：

```text
DADS开发F1下降 ≤ 0.001
DADS Recall下降 ≤ 0.002
DADS Specificity下降 ≤ 0.002
开发OOD总体F1提高 ≥ 0.003
低FPR pAUC提高 ≥ 0.01
TPR@1% FPR提高 ≥ 0.02
最差UAV来源Recall提高 ≥ 0.03
低SNR Recall不得下降
背景来源宏平均FPR增加 ≤ 0.005
所有Logit、Loss和梯度必须有限
```

门槛应根据固定开发集基线预检结果落盘，正式训练开始后不得修改。

### 12.2 多随机种子

seed 42全部通过后才能运行：

```text
seed 43
seed 44
```

最终开发结论使用三随机种子均值、标准差和最差seed，不以单个最好seed晋级。

### 12.3 终止条件

满足任意一项立即停止当前路线：

- 高频输入实为伪上采样；
- 高频分支主要学习设备身份而非UAV特征；
- DADS非劣门槛失败；
- 最差UAV来源性能下降；
- 背景FPR超限；
- 高频分支与G7无有效互补；
- 多seed结果不稳定；
- 训练出现无法恢复的非有限梯度或CUDA错误；
- 需要读取已锁定测试集才能继续调参。

## 13. 最终确认原则

G17通过全部开发门槛后：

1. 冻结模型检查点；
2. 冻结融合权重；
3. 冻结温度；
4. 冻结严格模式和平衡模式阈值；
5. 记录配置、代码、清单、检查点和预测SHA256；
6. 建立新的、从未参与开发的来源隔离外部确认集；
7. 只运行一次最终评估；
8. 根据预注册门槛决定是否替代G7。

Unseen、Real-world和G13只能作为历史证据，不得成为G17最终晋级依据。

## 16. 预期收益与风险

### 16.1 预期收益

- 保留G7正式检查点和回退能力；
- 恢复16 kHz分支丢失的高频旋翼信息；
- 提高不同机型之间的互补识别能力；
- 在较低风险下验证Late Fusion思想；
- 比10个相似CNN集成更节省训练和推理成本；
- 比直接全模型微调更容易控制DADS性能退化。

### 16.2 主要风险

- 高频差异可能来自设备而非UAV；
- 允许开发数据可能缺少真实高频信息；
- 两个分支错误可能高度相关；
- 融合可能提高Recall但增加FPR；
- Tune来源数量有限，融合权重可能过拟合；
- 双分支增加部署延迟和显存；
- 新外部确认集仍可能揭示未覆盖的来源域偏移。

所有收益必须通过预注册门槛和新的独立外部确认验证，不能根据开发集提升直接宣称正式
模型已经改进。

---

## 17. 当前结论

G17值得作为下一阶段参考方案，但首要步骤不是直接训练新模型，而是执行P0高频可行性
审计。

只有确认允许开发的数据确实保留8 kHz以上有效、可泛化且非设备泄漏的声学信息后，
才构建高频辅助CNN。随后通过受约束Late Fusion与G7组合，并使用DADS非劣、低FPR、
最差来源和低SNR门槛共同决定是否继续。

本方案的核心原则是：

> 借鉴论文的多机型、多背景和后融合思想，同时保留现有工程更严格的数据隔离、低误报
> 评价和一次性最终测试制度。

## 18. G17-P0实施结果

### 18.1 实现范围

P0已经实现为只读审计：

```text
configs/g17_p0_high_rate.yaml
scripts/run_g17_p0_audit.sh
src/dads_crnn/audit_g17_high_rate.py
tests/test_g17_high_rate_audit.py
```

审计直接读取G14允许开发数据的原始ZIP成员，不使用G15生成的16 kHz片段缓存。采用
按`split × label × source_group`分层的确定性抽样，每个来源组最多抽取8条录音，
每条录音分析最多3个一秒时间窗。

运行过程中：

- 不训练模型；
- 不执行模型推理；
- 不写模型检查点；
- 不读取Unseen、Real-world或G13音频；
- 对原始清单全部34,659行执行封存路径和55,000个已消费音频哈希防火墙检查。

### 18.3 结果解释限制

当前开发数据存在明确的`dataset_label_confounding`：

- Kielce提供UAV正类；
- TAU提供背景负类。

因此0.976205的高频能量AUC不能解释为“高频能量本身已经能泛化检测UAV”，其中可能
包含录音设备、采集地点和数据集处理流程差异。P1必须继续使用来源平衡、来源隔离和
与G7错误互补性分析，不能仅凭高频分支自身AUC晋级。

“伪上采样”也不能仅凭频谱自动完全证明。P0采用保守谱截止标志：如果8 kHz以上能量
低于阈值，则标记为疑似高频缺失；该标志只用于筛查，不作为录音历史的法证结论。
