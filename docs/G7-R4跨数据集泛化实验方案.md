# G7-R4跨数据集泛化实验方案

## 1. 任务边界

G7-R4优化的是“输入来自训练阶段未见过的无人机/环境时，能否仍判断为无人机”的二分类能力。它不做无人机具体型号识别，也不做未知型号拒识。

固定主线为：0.5秒波形 → PANNs Cnn14_16k → 无人机概率 → 多片段录音级均值聚合。

## 2. 为什么不能直接沿用G15/G16

G15与G16采用1秒输入并且只训练二分类头。G15将Kielce/TAU开发F1从0.989505提高到最高0.991202，但没有达到预注册的0.005增益；G16虽然改善部分排序指标，却使-15 dB、-10 dB正样本TPR下降约0.013至0.022，因此都未晋级。

R4保持已经晋级的G7-R2原生0.5秒输入。Kielce/TAU已有1秒缓存不重写，而是通过显式样本偏移生成前后两个无重叠0.5秒视图，避免只取前半段。

## 3. 数据角色

| 角色 | 数据 | 用途 |
|---|---|---|
| 训练 | DADS train | 保持原任务能力，防止灾难性遗忘 |
| 训练 | Kielce train | 增加不同无人机、距离和采集条件的正样本 |
| 训练 | TAU train | 增加城市环境负样本 |
| 训练 | G9机械声 | 抑制旋翼相似机械声误报 |
| 开发 | DADS validation | 域内回归门槛 |
| 开发 | Kielce tune + TAU tune | 候选选择和阈值开发 |
| 锁定确认 | Kielce dev_holdout + TAU dev_holdout | 候选冻结后一次性确认 |

Kielce dev_holdout中的Phantom4、S900、X6D、Y6不进入训练或选模。G13已经被消费，只能作为历史误差依据，不能再次包装成新独立测试。NASA数据因训练许可不明确继续禁用。

## 4. R4-A算法

R4-A从G7-R2 `pt_mic_bg_freq` seed 42权重初始化，保留原来的麦克风响应模拟、背景混合和频率遮挡，仅增加：

1. 按正负类别严格平衡每个batch；
2. 在类别内部按DADS、Kielce型号、TAU场景和G9机械类别进行平方根来源均衡；
3. 冻结频谱前端、六个卷积块及BatchNorm统计量，只解冻`fc1`和二分类头；
4. 使用`1e-5`小学习率，DADS回放承担遗忘保护。

只训练头在G15/G16中已经不足；直接解冻卷积块则参数变化过大。有限解冻`fc1`是两者之间风险可控的选择。R4-A是可行性候选，后续仍需用消融区分“来源均衡”和“有限解冻”的贡献。

## 5. 晋级规则

开发阶段至少满足：DADS validation F1下降不超过0.003；TAU tune FPR增加不超过0.005；Kielce tune Recall提高至少0.005；低信噪比召回不得下降。

通过后才允许执行R4-B训练集内困难正样本挖掘；R4-B通过后才执行R4-C低信噪比课程学习。最终冻结一个候选，用三个随机种子报告均值与标准差，再一次性读取锁定确认集。

锁定确认报告ROC-AUC、PR-AUC、FPR≤0.05标准化pAUC、FPR=1%/5%时TPR、来源宏平均TPR、最差来源TPR和录音级Recall。

## 6. 运行

```bash
bash scripts/run_g7_r4_cross_dataset.sh prepare
CUDA_VISIBLE_DEVICES=0 bash scripts/run_g7_r4_cross_dataset.sh preflight
CUDA_VISIBLE_DEVICES=0 nohup bash scripts/run_g7_r4_cross_dataset.sh train 42 \
  > logs/g7_r4a_seed42.log 2>&1 &
tail -f logs/g7_r4a_seed42.log
```

当前阶段不得手工读取或评估`dev_holdout`。

## 7. R4-A seed 42开发结果

R4-A完成8个epoch，最佳检查点位于epoch 7。与同为seed 42的G7-R2基线比较：

| 指标 | G7-R2 | R4-A | 差值 |
|---|---:|---:|---:|
| DADS开发F1 | 0.996585 | 0.995008 | -0.001577 |
| Kielce片段Recall | 0.981445 | 0.986816 | +0.005371 |
| Kielce来源宏平均Recall | 0.981443 | 0.986772 | +0.005329 |
| Kielce最差来源Recall | 0.972694 | 0.979336 | +0.006642 |
| TAU片段FPR | 0.010986 | 0.010498 | -0.000488 |
| Kielce/TAU ROC-AUC | 0.997549 | 0.998514 | +0.000965 |
| Kielce/TAU PR-AUC | 0.998077 | 0.998902 | +0.000825 |
| 标准化pAUC，FPR≤0.05 | 0.991105 | 0.994685 | +0.003580 |
| TPR@校准FPR=1% | 0.979980 | 0.986328 | +0.006348 |
| TPR@校准FPR=5% | 0.989502 | 0.994873 | +0.005371 |

固定阈值0.5的低信噪比检查中，-10 dB TPR提高0.034167，但-15 dB TPR下降
0.010833，因此原始预注册门槛判定为`do_not_promote_r4a`。同时，-15 dB条件下
背景FPR由0.356667降至0.298333、配对排序准确率由0.856667升至0.895000，说明
R4-A的主要问题更接近输出分数整体下移和阈值迁移，而不是正负排序能力退化。

该结论仅来自已消费开发数据；`dev_holdout`仍未读取。下一步先报告每个SNR在相同
目标FPR下的TPR，原固定阈值门槛和“不晋级”结论保持不变，不能事后删除。

## 8. R4-B低信噪比分层混合

R4-B以R4-A为严格对照，重新从同一个G7-R2 seed 42检查点开始训练。除正样本背景
混合SNR分布外，数据、随机种子、模型、解冻范围、采样、学习率和训练轮数均保持不变。
混合样本中的30%取自-15/-10 dB，折算为全部正样本视图的期望占比9.9%。配置差异
审计已通过。

| 指标 | G7-R2 | R4-A | R4-B |
|---|---:|---:|---:|
| DADS开发F1 | 0.996585 | 0.995008 | 0.992837 |
| Kielce Recall | 0.981445 | 0.986816 | 0.989990 |
| Kielce最差来源Recall | 0.972694 | 0.979336 | 0.980812 |
| TAU FPR | 0.010986 | 0.010498 | 0.014648 |
| 跨域ROC-AUC | 0.997549 | 0.998514 | 0.999015 |
| 跨域标准化pAUC | 0.991105 | 0.994685 | 0.995329 |
| 跨域TPR@FPR=1% | 0.979980 | 0.986328 | 0.987793 |
| 跨域TPR@FPR=5% | 0.989502 | 0.994873 | 0.997070 |
| -15 dB固定阈值TPR | 0.478333 | 0.467500 | 0.505000 |
| -10 dB固定阈值TPR | 0.536667 | 0.570833 | 0.610000 |

R4-B证明低信噪比分层训练能够修复R4-A的固定阈值召回问题，但相对G7-R2的DADS F1
下降0.003748，超过预注册上限0.003。因此R4-B判定为`do_not_promote_candidate`，不做
三随机种子，也不读取锁定Holdout。

从剂量响应看，9.9%的低信噪比正样本暴露可能偏强：低SNR与跨域排序继续提高，但
域内F1和TAU固定阈值FPR变差。若继续开发，应预注册一个更低暴露比例的单点实验，
而不是在同一开发集上反复搜索多个权重。

## 9. R4-C保守低信噪比剂量

R4-C是本开发集上的最后一个预注册权重点。它只将低信噪比困难视图在全部正样本中的
期望占比从R4-B的9.9%降至4.95%，其余字段与R4-B完全一致。seed 42最佳检查点位于
epoch 4。

| 指标 | G7-R2 | R4-A | R4-B | R4-C |
|---|---:|---:|---:|---:|
| DADS开发F1 | 0.996585 | 0.995008 | 0.992837 | 0.994286 |
| Kielce Recall | 0.981445 | 0.986816 | 0.989990 | 0.988770 |
| Kielce最差来源Recall | 0.972694 | 0.979336 | 0.980812 | 0.980074 |
| TAU FPR | 0.010986 | 0.010498 | 0.014648 | 0.012695 |
| 跨域ROC-AUC | 0.997549 | 0.998514 | 0.999015 | 0.998851 |
| 跨域标准化pAUC | 0.991105 | 0.994685 | 0.995329 | 0.994893 |
| TPR@FPR=1% | 0.979980 | 0.986328 | 0.987793 | 0.987305 |
| TPR@FPR=5% | 0.989502 | 0.994873 | 0.997070 | 0.996582 |
| -15 dB固定阈值TPR | 0.478333 | 0.467500 | 0.505000 | 0.500833 |
| -10 dB固定阈值TPR | 0.536667 | 0.570833 | 0.610000 | 0.597500 |

相对G7-R2，R4-C的DADS F1下降0.002300、TAU FPR增加0.001709，均在门槛内；
Kielce Recall提高0.007324，-15/-10 dB固定阈值TPR分别提高0.022500和0.060833。
四项门槛全部通过，判定为`promote_candidate_to_multiseed`。下一步只确认seed 43/44，
不再搜索新的低信噪比权重。

## 10. R4-C三随机种子确认

seed 43和44使用同一G7-R2 seed 42初始检查点，只改变训练采样与增强随机性。确认规则为
每个seed都必须通过全部开发门槛，禁止只选择表现最好的seed。

| seed | DADS安全 | TAU安全 | Kielce增益 | 低SNR非劣 | 总判定 |
|---:|---|---|---|---|---|
| 42 | 通过 | 通过 | 通过 | 通过 | 通过 |
| 43 | 通过 | 通过 | 通过 | 未通过 | 未通过 |
| 44 | 通过 | 通过 | 通过 | 未通过 | 未通过 |

seed 43和44在-15 dB固定阈值TPR上分别比G7-R2下降0.006667和0.007500，虽然二者
在-10 dB、Kielce、跨域AUC及低FPR指标上仍有改善。R4-C因此判定为
`terminate_r4c_not_stable_across_seeds`，不能冻结为锁定确认候选，不读取Holdout。

同一开发集上的低SNR权重搜索到此结束。后续若继续，应改变方法假设，例如使用显式
低FPR排序目标或校准约束，而不是继续微调-15/-10 dB样本比例。
