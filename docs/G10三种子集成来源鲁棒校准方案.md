# G10三种子集成来源鲁棒校准方案

## 目的

G9三个随机种子的外部排序能力均优于G7，但seed 44在val_ood的严格低误报工作点出现tune到holdout的阈值迁移。G10不再训练模型，只组合冻结的G9 seed 42、43、44检查点输出，并改善阈值稳定性。

## 冻结规则

1. 对同一样本的三个raw logit取算术平均；禁止挑选单个最佳种子。
2. 温度参数仅由val_ood tune标签拟合。
3. 阈值选择只使用val_ood tune负类及其`background_source`分组。
4. 目标FPR为1%时采用90%来源覆盖阶数；目标FPR为5%时采用75%来源覆盖阶数。
5. 来源阈值不得低于pooled经验阈值。
6. tune正类不参与阈值选择，仅执行可行性检查：来源阈值下的TPR必须至少保留pooled阈值TPR的90%。不可行时停止，不得利用holdout放宽规则。
7. 校准文件写入后不可覆盖。holdout只能使用冻结校准执行一次评估。

## 晋级条件

在两个工作点上，G10相对冻结G7基线必须同时满足：holdout FPR不升、TPR不降、F1不降、UAV来源宏平均TPR不降、背景来源宏平均FPR不升。三个排序指标也必须全部不低于G7。

## 数据隔离

G10仅允许读取val_ood tune和holdout。Unseen、Real-world及其他最终测试集继续锁定。所有输入清单、预测文件、配置、实现和本文件均记录SHA256。
