> 第二阶段执行记录见：[G7第二阶段：IDMT跨域背景R0基线](G7第二阶段R0跨域基线.md)。

## 1. 计划目标

当前正式二分类检测模型为：

```text
G7 PANNs Cnn14_16k AudioSet预训练模型（seed 42）
```

G7在历史 DADS 同数据源已消费内部回归集上已经接近饱和：

| 指标 | G7历史DADS已消费内部回归集 |
|---|---:|
| Accuracy | 0.996426 |
| Precision | 0.995422 |
| Recall/TPR | 0.998567 |
| Specificity | 0.993305 |
| FPR | 0.006695 |
| F1 | 0.996992 |
| ROC-AUC | 0.999854 |
| PR-AUC | 0.999913 |

该历史清单实际是在每个标签内随机把Parquet行（`AudioRef`）分配到Train、
Validation和Test，再把每行展开成1秒片段；同一行的片段不跨split，但
`source_path`不是实际分组键，其零交集只是事后身份审计结果。后验原始WAV字节级
SHA256审计发现15个重复哈希组，共涉及30条Parquet记录；每组保留1条并移除15条，
其中6组成员原本跨至少两个split，连带移除244条历史1秒manifest片段。历史原Test还
被多轮候选门禁消费。

旧`dads_dedup_v2`只去除这些原始WAV字节级精确重复，仍复用历史1秒
`loop/tail_loop`预处理和缓存，未消除标签相关的时长/重复捷径。因此新主线不能继续
以dedup v2为训练底座，而应使用`dads_native_half_second_content_component_v2`：
从原始WAV生成16 kHz、8000采样点的原生0.5秒窗口，不循环、不补齐、不拉伸，并让
原始与最终模型输入内容组件整体划分。由于DADS还缺少会话、设备、场景和型号元数据，
上述数值只能作为同数据源已消费内部回归结果，不代表独立外部泛化。

继续把历史DADS同数据源内部回归Accuracy从99.64%提高到99.7%以上，研究价值和实际
收益都很有限。G7后续改进的主要目标调整为：

> 从历史DADS同数据源内部回归指标优化，转向跨域召回、低误报阈值迁移和低信噪比检测。

本计划只针对“无人机/非无人机”二分类检测模块，不涉及G18/G22的已知型号九分类，也
不涉及未知型号拒识。

## 2. 当前主要问题

### 2.1 历史同源回归指标高，但外部泛化不足

G7在G13一次性外部确认集上的结果为：

| 指标 | G13外部确认 |
|---|---:|
| Recall/TPR | 0.550854 |
| Specificity | 0.974361 |
| FPR | 0.025639 |
| F1 | 0.6165 |
| ROC-AUC | 0.9175 |
| PR-AUC | 0.6836 |
| 最差UAV来源Recall | 0.117241 |

这说明G7在历史DADS同源回归数据上指标很高，但遇到新设备、新地点、新无人机来源和
不同信噪比时，召回率明显下降。

### 2.2 阈值迁移不稳定

在`val_ood`中，以Tune背景校准目标FPR后应用到Holdout：

| 目标工作点 | Holdout TPR | Holdout实际FPR |
|---|---:|---:|
| 目标FPR 1% | 0.236986 | 0.037685 |
| 目标FPR 5% | 0.394521 | 0.090175 |

目标1%的阈值迁移后产生3.77%的实际FPR，目标5%的阈值迁移后产生9.02%的实际FPR。
因此当前主要问题不只是分类分数，而是不同背景域之间的分数分布发生偏移。

### 2.3 正式G7只有一个随机种子

正式检查点只有seed 42。缺少seed 43、44意味着当前无法充分说明训练稳定性。后续正式
候选必须至少报告三个随机种子的均值和样本标准差。

## 3. 公开论文对本计划的启示

Reuter等人在2026年的公开研究中采用AudioSet预训练、无人机专用增强、固定FPR评价和
跨数据集测试。在目标FPR为1%时，其完整增强模型在AuDroK OOD上的平均TPR达到0.825。

论文表明：

1. AudioSet预训练是跨域提升的主要来源；
2. 麦克风频响模拟能够明显改善跨设备泛化；
3. 背景混合、频率遮挡和无人机变调进一步改善困难域；
4. 1秒窗口适合低延迟，2秒窗口对中远距离弱信号更有利；
5. 只报告Accuracy不能反映实际长期监测性能；
6. 片段级FPR为1%仍可能产生约每小时36个误报片段，需要事件级聚合。

本工程不直接照搬论文模型，而是在保持G7 PANNs主干和正式基线可比性的前提下，逐项
验证数据和增强策略。

参考论文：

```text
Paul M. Reuter, Mattes Ohlenbusch, Christian Rollwage.
Improving Acoustic Drone Detection Generalization Through
Pretraining and Data Augmentation. 2026.
https://arxiv.org/abs/2605.31329
```

### 4.2 不能把下载量直接当作新增数据量

DADS本身是多个公开数据源的聚合集，其中可能已经包含：

- AuDroK；
- DroneNoise；
- ESC-50或其派生背景；
- 其他公开无人机声音。

因此，重新下载原始数据后不能直接与DADS合并。必须先检查：

1. 原始文件SHA256；
2. 解码后PCM SHA256；
3. 重采样后音频指纹；
4. 文件名和来源标识；
5. 录音会话、日期、地点、设备和无人机型号；
6. 是否存在相同录音的转码、裁剪或音量变化版本。

重新下载AuDroK和DroneNoise的首要价值可能是恢复原始会话和设备元数据，而不是增加
新的音频时长。

### 4.3 已经消费的数据不能重新定义为全新测试集

以下数据已经参与过工程训练、开发或正式分析：

- DADS历史Train、Validation和已消费内部回归原Test；
- `val_ood` Tune和Holdout；
- ESC-50困难负类及Guard；
- 旧Unseen和Real-world；
- G13外部确认集；
- 已经查看过结果的NASA、Kielce或其他开发数据。

这些数据仍可用于训练、开发回归和历史对照，但不能再称为全新无偏最终测试集。

## 5. 数据接入和审计流程

### 5.1 原始数据登记

每个新增数据集必须建立独立登记表，至少包含：

```text
dataset_name
source_url
license
download_date
archive_sha256
original_file_sha256
decoded_pcm_sha256
recording_id
session_id
location_id
device_id
microphone_id
uav_model
distance
height
sample_rate
channels
duration
label
intended_role
```

其中`intended_role`必须在第一次模型推理前确定为：

```text
train
validation
calibration
development_test
final_holdout
```

### 5.2 排重层级

排重不能只比较文件名，必须执行：

```text
压缩包SHA256
  ↓
原始文件SHA256
  ↓
解码PCM SHA256
  ↓
统一采样率后的音频指纹
  ↓
来源、会话、地点、设备元数据检查
```

对疑似同源但经过转码、增益调整、声道转换或裁剪的数据，应按同一原始录音组处理。

### 5.3 禁止相邻切片泄漏

同一条长录音切出的多个1秒片段高度相关，必须先按原始录音或会话划分，再切片：

```text
原始录音/飞行会话
  ↓ 分配数据角色
Train / Validation / Calibration / Test
  ↓
各自独立切成1秒或2秒窗口
```

禁止先切成片段后随机分配到不同集合。

上面是新增外部长录音的一般规则。DADS主重训必须单独采用原生0.5秒协议：从原始WAV
直接提取完整8000点窗口，丢弃不足0.5秒的尾部或录音，禁止`loop`、`tail_loop`、
重复、补零、镜像或拉伸；原始哈希和最终float32/PCM16模型输入哈希形成的内容组件
必须整体进入同一split。

## 6. 推荐的数据划分

### 6.1 五类数据角色

| 数据角色 | 用途 | 是否允许影响参数 |
|---|---|---|
| Train | 更新模型权重 | 是 |
| Validation | 早停和检查训练过程 | 不直接更新，只影响模型选择 |
| Calibration | 只用背景分数确定FPR阈值 | 只允许拟合温度/阈值 |
| Development Test | 比较候选和做消融 | 不更新模型 |
| Final Holdout | 一次性最终确认 | 完全禁止开发使用 |

### 6.2 推荐示例

```text
Train
├── DADS native 0.5秒内容组件隔离版训练部分
├── 新增NASA训练飞行
└── 新增DroneNoise训练会话

Validation
├── 不同NASA飞行批次
└── 不同DroneNoise会话

Calibration
└── 独立背景来源，只使用负类确定1%和5% FPR阈值

Development Test
├── 一个完整外部UAV来源
└── 一个完整外部背景来源

Final Holdout
├── 从未推理的新设备/新地点UAV
└── 从未推理的新背景来源
```

新增数据不足时，宁可减少训练数据，也要保留真正独立的最终确认来源。

## 7. 低信噪比数据构造

### 7.1 合成SNR条件

使用干净UAV录音与独立背景混合：

```text
SNR ∈ {-15, -10, -5, 0, +5, +10} dB
```

建议对每个原始UAV录音和背景录音保留身份字段，防止同一原始声音的不同混合版本跨越
Train和Test。

### 7.2 合成片段不等于独立样本

通过增强生成10万个片段不能称为增加10万个独立录音。论文中必须分别报告：

- 独立原始录音数量；
- 独立会话数量；
- 独立设备数量；
- 合成增强片段数量；
- 实际音频时长；
- 不同SNR条件的样本数。

### 7.3 真实低SNR测试

最终低SNR结论不能只来自人工混合。至少需要一种真实弱信号数据：

- 远距离飞越；
- 强交通背景；
- 风噪环境；
- 不同麦克风设备；
- 真实室外反射和遮挡；
- 可获得真实距离标注的NASA、UaVirBASE或IDMT Berne数据。

DroneAudioSet的录音设备和任务更偏向机载听觉，不能未经验证就当成地面远距离无人机
检测数据。它适合作为辅助低SNR研究，不宜直接替代地面外部测试集。

## 8. 分阶段算法实验

所有实验保持相同数据清单、随机种子和评价协议，每次只改变一个因素。

### G7-R0：冻结基线复测

目的：

- 不重新训练G7；
- 在新增开发数据上建立跨域基线；
- 输出来源、设备、距离和SNR分组指标。

### G7-R1：结构化麦克风频响模拟

G7已经具有`8个随机锚点 + FFT插值`的通用平滑频响增强，因此R1不是“首次加入频响
增强”，而是只替换这一子模块，其他训练条件保持不变：

- 随机高通；
- 随机低通；
- 2～3段峰值均衡；
- 峰值均衡增益限制在±4 dB；
- 保持其他训练条件不变。

由于增强末尾会执行峰值归一化，单纯的全局增益会被抵消，所以R1不加入无效的全局
增益项。增强概率继续保持G7原值`0.50`，用于隔离“频响结构变化”本身的效果。

该阶段重点观察跨设备TPR和外部背景FPR，不以历史DADS内部回归Accuracy作为主晋级依据。

执行状态：**seed 42已完成并否决**。R1通过历史DADS已消费内部回归、`val_ood`
开发和G9门禁，但在IDMT-TRAFFIC Development Test上的严格FPR由G7/R0的
`0.066789`上升到
`0.179854`，6项IDMT门禁全部失败。不运行seed 43/44，不读取Final Holdout。

复核发现原频响和结构化频响共用增强器随机数流，两个算子消耗随机数的数量不同，
会改变后续混响、彩色噪声和时移轨迹。当前候选的否决结论有效，但不能把全部退化严格
因果归于IIR算子。进入R2之前，先用独立随机流同期训练`C0=smooth_fft`与
`C1=structured IIR`，保证所有非频响增强逐样本一致。

完整结果见：

[G7第三阶段：R1结构化麦克风频响实验报告](G7第三阶段R1结构化麦克风频响实验报告.md)

### G7-R2：扩展低SNR背景混合

R2需等待R1独立随机流配对实验完成。由于原R1候选已经否决，R2不能继续叠加在R1
上；R2应从正式G7/R0重新分支，只改变低SNR正类背景混合这一项：

```text
-15、-10、-5、0、+5、+10 dB
```

低SNR采样比例必须预先固定。若低SNR召回提高但正常SNR、外部背景FPR或最差来源指标
明显退化，则不晋级。

### G7-R3：无人机正类变调

只对UAV正样本进行小幅变调，用于模拟：

- 转速变化；
- 旋翼基频变化；
- 载荷和飞行状态差异。

变调范围不能过大，避免制造不真实的旋翼声。

### G7-R4：Mel频率遮挡

只增加轻量频率遮挡，不使用时间遮挡，以尽量保留无人机的周期包络和持续性结构。

### G7-R5：1秒与2秒录音聚合

比较：

```text
1秒独立判定
2秒直接输入
多个1秒Logit的事件级聚合
```

重点分析50米以上、低SNR和间歇性弱信号。必须同时报告延迟和计算量。

### G7-R6：受约束域适配

只有前述数据和增强策略仍不能解决跨域问题时，才考虑：

- 冻结大部分PANNs主干；
- 只训练二分类头或最后一层；
- 较小学习率；
- L2-SP或教师模型约束；
- 保持原G7分布上的回归保护。

不得直接用新增外部测试集反复适配。

## 9. 主要评价指标

### 9.1 主指标

后续候选主要报告：

```text
TPR@1% FPR
TPR@5% FPR
外部背景实际FPR
FPR≤0.05标准化pAUC
最差UAV来源Recall
UAV来源Macro Recall
背景来源Macro FPR
每小时误报告警数
```

### 9.2 补充指标

同时报告：

- Accuracy；
- Precision；
- Recall；
- Specificity；
- F1；
- ROC-AUC；
- PR-AUC；
- 混淆矩阵；
- 不同距离/SNR/设备/场景的分组结果；
- seed 42、43、44的均值与样本标准差。

### 9.3 事件级指标

片段级FPR不能直接等同于实际告警数量。连续监测还应报告：

- 每小时误报事件数；
- 事件级Recall；
- 平均检测延迟；
- 最短持续时间；
- 迟滞阈值；
- 相邻阳性片段合并规则。

## 10. 候选晋级原则

候选模型必须同时满足：

1. 历史DADS同数据源内部回归F1、Recall和Specificity不超过预设容差退化；
2. 跨域平均TPR提高；
3. 最差UAV来源Recall不下降；
4. 目标1%和5% FPR阈值的迁移误差减小；
5. 外部困难背景FPR不恶化；
6. 至少两个随机种子呈同方向改善；
7. 三随机种子均值优于G7基线；
8. 不读取或反复利用Final Holdout；
9. 不通过事后选择最优seed或最优测试阈值获得提升。

具体数值门槛必须在正式运行前根据新增开发数据规模、二项置信区间分辨率和当前G7
基线预注册，不能看到测试结果后修改。

## 11. 推荐执行顺序

### 阶段A：数据准备

1. 冻结当前G7检查点、配置和已有预测；
2. 从DADS原始WAV生成原生8000点窗口，禁止复用旧1秒缓存，并记录原始、float32和
   PCM16内容哈希；
3. 下载并保存新增数据的许可、引用和压缩包SHA256；
4. 优先整理IDMT-TRAFFIC、DroneNoise、NASA Small UAS和UaVirBASE；
5. 恢复AuDroK/DroneNoise的原始来源、会话和设备元数据；
6. 与DADS、ESC-50、G13及其他已有数据执行多层排重；
7. 输出新增的独立录音、会话、设备和时长统计。

### 阶段B：冻结数据角色

1. 在任何模型推理前分配Train、Validation、Calibration和Test角色；
2. 保留至少一个从未推理的最终确认来源；
3. 生成SHA256绑定的数据注册表；
4. 检查所有集合在录音、会话、地点和设备层的交集；
5. 对DADS同时检查原始内容组件与最终模型输入内容组件均不跨split，并明确原Test
   已消费，不能包装成fresh holdout。

### 阶段C：建立G7跨域基线

1. 不训练，直接使用正式G7；
2. 在新增Development Test上推理；
3. 报告低FPR、来源、距离、设备和SNR指标；
4. 确定最主要的失败域。

### 阶段D：单因素消融

按以下顺序运行：

```text
正式G7/R0
  ├─ R1 麦克风频响（已否决）
  ├─ R2 低SNR混合
  ├─ R3 正类变调
  └─ R4 频率遮挡
```

每个基础增强先作为正式G7/R0的独立单变量分支。未通过门槛的模块停止，不叠加到下一
候选；只有独立通过的模块，才能另行预注册组合消融。R5事件级聚合和R6受约束域适配
继续作为后续独立阶段。

### 阶段E：多随机种子和最终确认

1. 开发阶段先使用seed 42进行可行性筛选；
2. 通过后运行seed 43和44；
3. 固定模型、增强、温度、阈值和聚合规则；
4. 一次性运行Final Holdout；
5. 输出最终报告后封存该测试集。

## 12. 最终论文建议

论文主题建议定位为：

> 面向跨设备、跨场景和低误报约束的声学无人机检测方法。

论文的核心比较应为：

```text
G7正式PANNs基线
  vs 麦克风响应增强
  vs 低SNR增强
  vs 变调/频率遮挡
  vs 1秒/2秒或事件级聚合
```

论文不能只报告内部Accuracy，应把以下结果放在主表：

- 跨域TPR@1% FPR；
- 跨域TPR@5% FPR；
- 外部背景FPR；
- 最差来源Recall；
- 距离和SNR曲线；
- 三随机种子均值与标准差；
- 数据来源和会话隔离方式；
- 训练、开发和最终测试的数据防火墙。

正确的研究目标不是让历史DADS同数据源内部回归Accuracy继续增加，而是：

> 在保持内部性能基本不退化的条件下，提高新设备、新地点、新无人机来源和低SNR条件
> 下的召回率，同时使校准阈值能够稳定迁移到外部背景。
