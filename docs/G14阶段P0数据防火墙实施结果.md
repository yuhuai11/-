## 4. 已实施的防护

统一防火墙覆盖：

- 输入路径的大小写、空格、连字符和下划线变体；
- 软链接解析后的真实目标；
- manifest 行中的数据集、来源、文件和路径字段；
- manifest 中与 G13 相同的音频 SHA256；
- PANNs训练入口；
- G9困难负类准备入口；
- BEATs数据准备入口；
- OOD温度与阈值校准入口；
- 来源稳健阈值及模型选择入口；
- 低 FPR 评价入口。

永久禁止用于开发的数据包括：

- G13 / `external_confirmation_v2`；
- 旧 Unseen；
- 旧 Real-world；
- 已登记的相关路径变体；
- 与 G13 音频内容哈希相同的复制或改名文件。
