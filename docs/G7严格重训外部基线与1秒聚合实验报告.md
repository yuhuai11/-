# G7严格重训外部基线与1秒聚合实验报告

更新日期：2026-08-07

## 1. 实验结论

P0严格三随机种子外部基线和P1非重叠1秒聚合均已完成。

主要结论：

1. 严格重训G7在DADS内部接近饱和，但外部背景误报仍然很高；
2. TAU Prague校准为1% FPR的阈值迁移到IDMT后，0.5秒切片实际FPR为
   `0.230321 ± 0.055244`，证明单一背景域阈值不能稳定迁移；
3. 保留原生0.5秒模型输入、把连续两个概率做非重叠均值，能在固定0.5阈值下同时
   提高外部无人机召回并降低背景误报；
4. 1秒聚合后重新使用TAU校准低FPR阈值，G13、IDMT和ESC-50的实际FPR反而上升，
   因此时间聚合有效，但跨域阈值校准问题尚未解决；
5. 当前数据不能构造独立的2秒校准单位，所以没有为了补齐表格而非法跨录音拼接。

所有外部数据均为已消费的可重复开发Benchmark。本报告不能表述为新的独立最终测试。

## 2. P0冻结输入

- 参考模型：G7-R2 `pt_mic_bg_freq` seed 42；
- 严格模型：`g7_strict_retrain_v1` seeds 42、43、44；
- 校准：4,480个TAU Prague负类0.5秒视图；
- Kielce/TAU：38,126个0.5秒视图；
- G13 DDL+AeroSonic：110,000个0.5秒视图；
- IDMT Traffic：58,692个0.5秒视图；
- ESC-50 guard：480个0.5秒视图。

每个模型独立在TAU Prague上校准1%和5% FPR阈值，Benchmark不参与模型、检查点或
阈值选择。

## 3. P0严格三随机种子外部结果

### 3.1 固定阈值0.5

| 数据集 | 指标 | 三seed均值 ± 标准差 |
|---|---|---:|
| Kielce/TAU | Recall | 0.920897 ± 0.015027 |
| Kielce/TAU | FPR | 0.011193 ± 0.000779 |
| Kielce/TAU | ROC-AUC | 0.990593 ± 0.002196 |
| G13 | Recall | 0.750804 ± 0.012129 |
| G13 | FPR | 0.093610 ± 0.001926 |
| G13 | ROC-AUC | 0.921953 ± 0.003453 |
| G13 | PR-AUC | 0.657687 ± 0.019936 |
| G13 | 标准化pAUC，FPR≤0.05 | 0.726201 ± 0.014215 |
| IDMT Traffic | FPR | 0.213482 ± 0.033123 |
| ESC-50 guard | FPR | 0.031250 ± 0.002083 |

Kielce/TAU仍存在“语料来源=标签”的混杂，只能作为开发诊断。G13来源组也是标签纯组，
IDMT与ESC-50则只有负类。

### 3.2 TAU校准1% FPR的跨域迁移

| 数据集 | 指标 | 三seed均值 ± 标准差 |
|---|---|---:|
| Kielce/TAU | Recall | 0.924322 ± 0.019654 |
| Kielce/TAU | 实际FPR | 0.013126 ± 0.001874 |
| G13 | Recall | 0.763703 ± 0.030028 |
| G13 | 实际FPR | 0.101185 ± 0.010276 |
| IDMT Traffic | 实际FPR | 0.230321 ± 0.055244 |
| ESC-50 guard | 实际FPR | 0.034722 ± 0.007887 |

校准阈值为`0.454183 ± 0.069279`。同一个“1% FPR”工作点迁移到IDMT后平均误报率
达到23.03%，是当前最明确的部署风险。

## 4. 检查点身份补充发现

G7-R2 seed 42与严格重训seed 42的模型参数逐张量完全相同，最大绝对差为0，五套数据
的预测数组也逐值完全相同。两个checkpoint文件SHA256不同，是因为保存的配置输出目录
不同，而不是模型权重不同。

这说明严格重训seed 42在相同训练数据、顺序和超参数下复现了R2结果。严格重训的新增
价值主要是修正的数据协议、近重复审计以及seed 43/44稳定性证据，不能把seed 42称为
相对R2的新算法提升。

## 5. P1非重叠1秒聚合

每两个连续0.5秒概率取算术平均，形成一个非重叠1秒决策。模型输入和权重均未改变。
所有数据都没有丢弃不完整尾段：

| 数据集 | 0.5秒视图 | 1秒决策 | 丢弃视图 |
|---|---:|---:|---:|
| Kielce/TAU | 38,126 | 19,063 | 0 |
| G13 | 110,000 | 55,000 | 0 |
| IDMT Traffic | 58,692 | 29,346 | 0 |
| ESC-50 guard | 480 | 240 | 0 |

### 5.1 固定阈值0.5

| 数据集/指标 | 0.5秒 | 1秒 | 变化 |
|---|---:|---:|---:|
| Kielce/TAU Recall | 0.920897 | 0.951454 | +0.030557 |
| Kielce/TAU FPR | 0.011193 | 0.006373 | -0.004820 |
| Kielce/TAU pAUC | 0.965004 | 0.983480 | +0.018476 |
| G13 Recall | 0.750804 | 0.783964 | +0.033160 |
| G13 FPR | 0.093610 | 0.083998 | -0.009611 |
| G13 ROC-AUC | 0.921953 | 0.936829 | +0.014876 |
| G13 PR-AUC | 0.657687 | 0.695486 | +0.037800 |
| G13 pAUC | 0.726201 | 0.742118 | +0.015917 |
| IDMT FPR | 0.213482 | 0.196120 | -0.017362 |
| ESC-50 FPR | 0.031250 | 0.026389 | -0.004861 |

固定阈值下所有主要方向均改善，且三个seed已经同时纳入均值和标准差。1秒聚合可以保留
为部署候选和后续模型实验的固定后处理基线。

### 5.2 重新校准1秒的1% FPR工作点

| 数据集/指标 | 0.5秒 | 1秒 | 变化 |
|---|---:|---:|---:|
| Kielce/TAU Recall | 0.924322 | 0.967524 | +0.043202 |
| Kielce/TAU实际FPR | 0.013126 | 0.012037 | -0.001089 |
| G13 Recall | 0.763703 | 0.836736 | +0.073033 |
| G13实际FPR | 0.101185 | 0.113924 | +0.012739 |
| IDMT实际FPR | 0.230321 | 0.282923 | +0.052602 |
| ESC-50实际FPR | 0.034722 | 0.044444 | +0.009722 |

1秒校准提高了无人机Recall，但代价是未见背景域误报增加。因此不能把TAU校准阈值
直接作为通用部署阈值；固定0.5和校准低FPR必须作为两个不同工作模式报告。

## 6. 两秒窗口为什么没有执行

当前冻结校准集的每条`recording_group`只有两个0.5秒视图，恰好只能构成一个1秒单位。
跨不同录音或不同设备拼成2秒会破坏连续时间语义并产生人为结果。因此本轮明确记录
`two_second_evaluation_performed=false`。后续只有获得同一原始录音中连续四个0.5秒
窗口的独立校准背景，才允许比较2秒工作点。

## 7. 下一步决策

1. 将“0.5秒输入＋非重叠1秒均值＋固定0.5阈值”设为当前最有证据的后处理候选；
2. 不再使用单一TAU背景继续搜索通用阈值；
3. 下一模型实验进入G7-R7频率域泛化消融：先做`Frequency MixStyle only`，不同时
   加Pitch或更换骨干；
4. R7仍以G13 pAUC、IDMT/ESC背景FPR和DADS安全门为晋级依据；
5. 只有R7单变量通过，才增加原始/增强视图一致性损失。
