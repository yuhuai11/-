# G12 严格模式跨来源保守校准结果

## 1. 决策

G12 内部 `val_ood holdout` 评估结论为：

`strict_candidate_ready_for_new_external_confirmation`

该结论只表示严格模式候选具备进入新外部确认集的资格，不代表已经正式替代 G7。平衡模式继续使用 G7。

- tune TPR 保留率：`0.8085106383`

## 4. 留一来源审计

- 审计来源数：25
- 达到目标 FPR 的留出来源：24
- 通过比例：96%
- 来源宏平均 FPR：0.003429
- 最坏留出来源 FPR：0.085714

最坏来源说明，任何有限来源校准都不能保证对所有未来背景绝对不退化。因此 G12 不能再次在已经消耗的 Unseen 或 Real-world 上调阈值；下一步必须使用新的独立外部确认集。

## 5. 下一步

1. 保持 G7 为当前正式模型。
2. G12 只作为严格模式候选；平衡模式保持 G7。
3. 构建新的、来源隔离的外部确认集。
4. 在读取新确认集之前冻结一次性评估协议。
5. 新确认集必须继续执行 FPR、TPR、F1、来源宏平均和低 FPR 排序门槛。
