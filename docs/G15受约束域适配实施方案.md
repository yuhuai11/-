# G15受约束域适配实施方案

## 1. 阶段目标

G14-D V2已经证明Kielce无人机数据能增强低SNR无人机响应，但G14-A仅分类头训练破坏
了DADS与机械困难负样本性能。G15不续训任何G14权重，而是从当前正式基线
G7 seed42重新初始化，在保留旧域行为的约束下吸收新增域信息。

G15是新候选实验，不替换、不覆盖G7。只有候选同时通过旧域回归门和新增域收益门，
才进入多seed复现；即使全部开发门通过，在取得新的独立外部确认集之前也不得晋级。

## 2. 数据边界

训练可使用：

- DADS去重版训练划分：旧任务正负样本回放；
- G9 `hn_train`：链锯、发动机、吸尘器、洗衣机等机械困难负样本；
- G14训练划分中的Kielce UAV正类与TAU城市背景负类；
- 已冻结G7教师在上述训练样本上的软输出。

开发选择可使用：

- DADS验证划分；
- G14 tune划分；
- G14-D V2 tune配对反事实集。

只允许在候选结构、损失权重和训练轮数完全固定后读取一次的开发回归审计：

- 已经被观察过的DADS test；
- 已经被观察过的G9 guard；
- G14 dev_holdout与G14-D V2 dev_holdout。

这些集合均已成为开发数据，不能再声称是最终独立测试。G13保持
`consumed_and_closed`，禁止读取其音频或再次用于模型选择。

## 3. 模型与损失

教师模型固定为G7 seed42，参数和BN统计均冻结。学生从同一G7检查点初始化。首个可行
性阶段只训练二分类头；若受约束分类头不能兼顾两域，再单独审议是否解冻最后一个
卷积块，不自动扩大训练范围。

总损失由三部分组成：

1. `L_supervised`：DADS、G9、Kielce和TAU上的有监督BCE；
2. `L_distill`：在DADS与G9回放样本上，使学生logit接近冻结G7教师logit；
3. `L_pair`：在G14训练配对中约束加入UAV后的logit高于同背景负样本，并随SNR增强。

推荐首个固定配置为：

```text
L = L_supervised + 1.0 * L_distill + 0.25 * L_pair
```

蒸馏使用logit空间的平滑L1或温度BCE，不对Kielce/TAU新域施加G7蒸馏，避免教师限制
新增域学习。机械困难负样本必须作为普通负样本进入训练，但不得被背景混合器当作
环境噪声再次叠加。

## 4. 采样设计

每个batch显式分成四个来源槽位，禁止只按总行数自然抽样：

- 32个DADS回放样本；
- 32个G9机械困难负样本；
- 32个Kielce UAV正样本；
- 32个TAU背景负样本。

来源内部按`source_group`平方根加权，物理录音组内有放回抽样；验证和审计集合不做
重采样。首轮固定seed 42、batch size 128、最多10 epoch，并使用DADS验证损失与G14
tune配对提升组成的双目标早停。不得只依据G14准确率保存检查点。

## 5. 两级门控

### G15-P1：CPU/GPU预检

预检必须证明：

- G7教师和学生初始SHA256正确；
- 学生初始化时与教师对同一batch的logit完全一致；
- 四来源batch数量准确，G9困难负样本不会进入背景混合；
- 三项损失有限且梯度有限；
- 仅训练声明范围内的参数；
- 未读取DADS test、G9 guard、G14 dev_holdout或G13。

### G15-P2：单seed可行性

seed42训练完成后先使用开发选择集。只有同时满足以下条件才允许执行一次回归审计：

- G14-D V2 tune四档SNR的平均提升均高于G7；
- tune单调率不低于80%；
- DADS验证F1不低于G7对应值减0.3个百分点；
- 没有通过提高统一阈值掩盖回归。

固定检查点和阈值后执行一次开发回归审计，建议门限为：

- DADS test F1不低于G7减0.5个百分点；
- DADS specificity不低于G7减1个百分点；
- G9 guard段级FPR不高于7.25%；
- G14 OOD holdout F1至少高于G7 3个百分点；
- G14-D V2 dev四档平均提升均高于G7，单调率不低于75%。

任一门失败即终止该候选，不通过阈值重校准补救，不进入多seed。全部通过后才运行
seed43和44，并要求三个seed全部通过相同门限。

## 6. 风险控制与最终结论边界

- G7检查点永久只读，G15使用独立输出目录；
- 所有训练清单、教师输出、检查点和评估结果记录SHA256；
- 不承诺训练必然提升，通过门控保证失败候选不会替换当前模型；
- G15开发成功只能说明方案值得外部确认，不能形成最终泛化结论；
- 最终晋级需要未参与G13/G14/G15设计和选择的新独立真实录音数据。

## 7. 实施顺序

1. 生成G15四来源训练清单与数据防火墙审计；
2. 实现冻结G7教师、蒸馏损失和配对排序损失；
3. 添加batch组成、梯度、初始化一致性单元测试；
4. 运行P1预检，确认不读取任何锁定开发/外部集合；
5. 只运行seed42可行性训练；
6. 根据双门控决定终止或进入多seed。

## 10. P1有限batch预检

P1使用固定128条batch：DADS 16正+16负、G9机械负样本32、Kielce UAV 32和TAU
背景32，因此监督标签总数为48正/80负。为了同时保留四来源等额和DADS正负回放，

来源槽位。冻结教师只对DADS与G9共64条旧域样本输出logit；学生从同一G7检查点
初始化。另将32条Kielce波形以−10 dB逐一叠加到32条TAU背景，计算正样本logit相对

- 教师与学生初始旧域logit最大误差不超过`1e-6`；

- 学生头部梯度有限，冻结学生参数与教师均无梯度；
- G9困难负样本没有进入背景混合；
- 配对RMS、SNR与峰值控制通过；
- 输入仅来自P0四个训练清单。

训练数据、固定开发子集、模型初始化、仅训练二分类头、batch组成、损失权重、学习率、

- DADS满足安全下限且G14 tune F1刷新历史安全最好值时，将`bad_epochs`清零；
- DADS不安全，或者G14没有超过历史安全最好值时，才累计`bad_epochs`；
- patience仍为3，只控制真正的平台期；
- 只有DADS安全且G14相对G7提高至少`0.005`时才写入`best.pt`；
- 未达到双门限时决策记为`terminate_no_dual_gate_checkpoint`，不再误写为没有DADS安全

### P3b运行时AMP溢出恢复

P3b首次正式运行在epoch 5的第300步之后遇到一次二分类头非有限梯度。最近完整断点为
epoch 4；检查确认断点模型参数全部有限、AMP scale为65536，失败epoch没有写入部分
检查点。故障来自训练器在`GradScaler.unscale_`之后把一次正常可恢复的AMP溢出直接
升级为致命错误，而不是让`GradScaler`跳过该optimizer step并降低scale。

修正版对AMP溢出采用以下封闭策略：

- 单次非有限梯度不执行参数更新，由`GradScaler`确认并降低scale；
- 日志记录epoch、step、缩放倍率变化和连续溢出次数；
- 每轮记录实际optimizer步数和AMP跳步数，损失只按实际更新步平均；
- 非AMP训练或预检出现非有限梯度仍立即失败；
- 连续AMP溢出超过8次立即失败；
- 只从epoch 4原子断点恢复，epoch 5完整重跑，不使用失败轮的任何部分状态。

该修正不改变数据、样本顺序、损失函数、学习率、模型可训练范围、早停门限或晋级门限。

`−0.00005`，接近不变；少数设备/SNR组合的排序准确率出现小幅负变化。固定阈值0.5
下低SNR正类TPR略降，同时背景FPR下降幅度更大，说明P3b主要扩大了配对判别间隔并
整体下移分数，而不是单纯提高无人机概率。

P4支持“受约束域适配机制有效，但单一−10 dB训练与固定阈值F1不能充分利用该机制”
的结论。下一实验应预注册多SNR受约束头部训练，使−15、−10、−5和0 dB直接进入
训练配对，并继续保留DADS安全门、背景FPR门和配对排序门。P4是终止后的tune开发
诊断，不能追认P3b晋级，也不能据此读取dev_holdout或最终测试集。

该预检会计算固定开发子集上的G7基准，并在正式batch上做一次前向/反向，但不执行
optimizer step、不写模型检查点、不启动正式训练。只有预检通过后才提供唯一一次
正式seed42命令。
